
# 이벤트
정해진 시점에 발동되는 메시지와 보상
- 월드를 처음 실행했을 때나 게임 오버가 되었을 때 등, 정해진 시점에 발동되어 전용 화면이 열립니다.
- 각 타이밍마다 하나씩 준비되어 있으며, 추가나 삭제는 할 수 없습니다. 사용하지 않는 타이밍은 공란으로 둡니다.
- 미션이나 작업 목록에는 표시되지 않습니다. 조건을 충족하면 달성으로 처리되는 항목은 작업으로 설정합니다.
- 보상은 발동과 동시에 자동으로 획득됩니다. 태스크와 같은 수령 절차나 리본도 없습니다.
- 発動時にカテゴリのレベル、アクションの実行回数、アイテムの所持数を変化させることができます。
- 이름·설명·아이콘을 비워두면, 플레이어에 내장된 기본 문구와 아이콘이 사용됩니다.

|타이밍|발동 조건|반복|
|-|-|-|
|`comebacked`|오프라인에서 1초 이상 꺼짐 후 복귀하고 진행 중인 액션이 있는 경우|여러 번|
|`gameovered`|전투에서 플레이어의 스태미나가 바닥났을 때|여러 번|
|`welcomed`|이 월드를 처음 시작했을 때|한 번만|
|`completed`|全カテゴリのレベルが最大値（maxCategoryLevels）に達した時|한 번만|
|`obtained`|특정 유형의 액션(보물상자 등)을 완료하거나 확인했을 때|여러 번|
- [_task_](ko/editor/task)
___

## 복귀 시
오프라인에서 복귀했을 때 발동
- 오프라인 상태로 1초 이상 지난 뒤 복귀했고, 진행 중인 액션이 있었을 때 발동합니다.
- 자리를 비운 동안의 진행 요약과 함께 표시됩니다.
___

### [_인포메이션_](ko/editor/information)
___

### カテゴリ
イベントでは使用しません
- ミッションやタスクの一覧に表示されないため、所属するカテゴリは指定しません。
- エディターでは入力欄が表示されません。
___

### タイミング
イベントが発動するタイミング（固定）
- `comebacked`로 고정되어 있어 편집할 수 없습니다.
- 복귀할 때마다 몇 번이든 발동합니다.
___

### 初期表示状態
イベントアイコンの初期表示状態（発火はタイミングで決まり、この設定では発火しません）
- イベントの発火条件はタイミングで決まり、この項目はアイコンの見た目のみに影響します。
- secreted: 全requirementsを満たすまでアイコンが表示されません（発火自体はタイミングで起こります）。
- hidden・hinted: アイコンに斜線が付き未解放として表示されます。
- released: 斜線が消え解放済みとして表示されます。
___

### 条件
報酬を獲得する条件
- タイミングが成立するとイベントは発動し、専用の画面を開いて内容を表示します。
- 報酬は、発動時にここで設定した条件を満たしている場合にのみ獲得します。
- 条件を設定していない場合は、発動するたびに報酬を獲得します。
- requiringGroupを有効にすると、ここで指定するidの意味がカテゴリ・アクション・アイテム個別のIDからグループIDに変わります。
___

#### 타입
조건으로 참조하는 요소의 종류

|타입|참조되는 값|
|-|-|
|カテゴリ|カテゴリのレベル|
|액션|액션 실행 횟수|
|아이템|아이템 보유 수|
___

#### 요소의 ID
조건으로 참조하는 요소의 ID
___

#### 값
요구사항에 필요한 값의 수
- 지정한 값 이상인 경우 조건을 만족합니다.
___

#### 소비 확률[0-1]
아이템이 소모될 확률(0~1, 타입이 아이템인 경우에만 유효)
- 조건을 충족하고 액션이 실행되었을 때 아이템이 소비될 확률입니다.
- `1`이면 반드시 소비하고, `0.5`이면 50% 확률로 소비하며, `0`이면 소비하지 않습니다.
- 기본값은 `1`(반드시 소비)입니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

#### 장비
아이템이 장비 상태일 것을 조건으로 할 것인지(타입이 아이템인 경우에만 유효)
- 활성화하면 아이템을 소지하고 있을 뿐만 아니라 장비가 장착되어 있는 것이 조건으로 요구사항이 됩니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

### 그룹 집계
조건의 id를 그룹 ID로 취급하여 소속 요소의 합계값으로 판정
- 활성화하면 조건(requirements)에 설정한 id는 기본 설정의 그룹 ID로 취급됩니다.
- Type이 카테고리인 조건은 해당 그룹에 속한 모든 카테고리의 레벨 합계로 판정합니다.
- Type이 액션인 조건은 해당 그룹에 속한 모든 액션의 실행 횟수 합계로 판정합니다.
- Type이 아이템인 조건은 해당 그룹에 속한 모든 아이템의 소지 수 합계로 판정합니다.
- 미해제(released 이외) 요소는 합계에 포함되지 않습니다.
- 아이템의 소비 확률(chance)과 장비 조건(equipment)은 무시되며, 소지 수를 소비하지도 않습니다. 판정에만 사용됩니다.
- 비활성화 시에는 기존과 같이 조건의 id는 개별 카테고리·액션·아이템의 ID로 취급됩니다.
___

### 報酬
イベント発動時の報酬設定
- タイミングが成立し、かつ条件を満たしている時に得られる報酬です。
- タスクと違って受け取る操作は要らず、発動と同時に自動で獲得します。
- 数量にマイナスを設定することができます。例えばゲームオーバー時にアイテムの数量をマイナスにすれば、それらを失います。
___

#### 타입
획득하는 요소의 종류

|타입|획득할 수 있는 것들|
|-|-|
|カテゴリ|레벨(경험치 환산으로 합산)|
|액션|실행 횟수|
|아이템|보유 수|
___

#### 요소의 ID
획득할 요소를 식별하는 ID
___

#### 값
취득하는 값
- 마이너스 값을 설정하면 소지 수, 실행 횟수, 레벨이 감소합니다. 단, 0 아래로는 내려가지 않습니다.
- 아이템에 최대 소유 수(MAXIMUM)가 설정되어 있는 경우, 그 값을 초과하여 소유 수가 증가하지 않습니다.
- タイプがカテゴリの場合、設定した値がレベルに直接加算されます（1で1レベル、0.5で0.5レベル）。アクションの経験値設定で調整するのが通常の方法です。特殊な目的がない限りこの設定は不要です。
___

#### 확률 [-1~1]
획득 성공 확률 (음수는 실패 시에만 평가됨)
- 획득 확률을 -1에서 1 사이의 소수로 설정합니다. 확률 판정에는 절대값이 사용됩니다.
- 값이 양수일 때는 액션 성공 시에만 판정되며, `1`이면 반드시 획득하고 `0.5`이면 50% 확률로 획득합니다.
- 값이 음수일 때는 액션 실패 시에만 판정되며, `-1`이면 반드시 획득하고 `-0.5`이면 50% 확률로 획득합니다.
- `0`인 경우 성공 시나 실패 시 모두 획득할 수 없습니다.
- 기본값은 `1`(성공 시 반드시 획득)입니다.
___

### タスクグループ
イベントでは使用しません
- ミッションやタスクの一覧に表示されないため、グループの指定は使いません。
- エディターでは入力欄が表示されません。
___

- 보상 수량에 마이너스를 설정하면 게임 오버에 대가를 부여할 수 있습니다.

#### 소비 확률[0-1]
아이템이 소모될 확률(0~1, 타입이 아이템인 경우에만 유효)
- 조건을 충족하고 액션이 실행되었을 때 아이템이 소비될 확률입니다.
- `1`이면 반드시 소비하고, `0.5`이면 50% 확률로 소비하며, `0`이면 소비하지 않습니다.
- 기본값은 `1`(반드시 소비)입니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

#### 장비
아이템이 장비 상태일 것을 조건으로 할 것인지(타입이 아이템인 경우에만 유효)
- 활성화하면 아이템을 소지하고 있을 뿐만 아니라 장비가 장착되어 있는 것이 조건으로 요구사항이 됩니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

### 그룹 집계
조건의 id를 그룹 ID로 취급하여 소속 요소의 합계값으로 판정
- 활성화하면 조건(requirements)에 설정한 id는 기본 설정의 그룹 ID로 취급됩니다.
- Type이 카테고리인 조건은 해당 그룹에 속한 모든 카테고리의 레벨 합계로 판정합니다.
- Type이 액션인 조건은 해당 그룹에 속한 모든 액션의 실행 횟수 합계로 판정합니다.
- Type이 아이템인 조건은 해당 그룹에 속한 모든 아이템의 소지 수 합계로 판정합니다.
- 미해제(released 이외) 요소는 합계에 포함되지 않습니다.
- 아이템의 소비 확률(chance)과 장비 조건(equipment)은 무시되며, 소지 수를 소비하지도 않습니다. 판정에만 사용됩니다.
- 비활성화 시에는 기존과 같이 조건의 id는 개별 카테고리·액션·아이템의 ID로 취급됩니다.

### 報酬

- タイミングが成立し、かつ条件を満たしている時に得られる報酬です。
- タスクと違って受け取る操作は要らず、発動と同時に自動で獲得します。
- 数量にマイナスを設定することができます。例えばゲームオーバー時にアイテムの数量をマイナスにすれば、それらを失います。

- 마이너스 값을 설정하면 소지 수, 실행 횟수, 레벨이 감소합니다. 단, 0 아래로는 내려가지 않습니다.
- 아이템에 최대 소유 수(MAXIMUM)가 설정되어 있는 경우, 그 값을 초과하여 소유 수가 증가하지 않습니다.
- タイプがカテゴリの場合、設定した値がレベルに直接加算されます（1で1レベル、0.5で0.5レベル）。アクションの経験値設定で調整するのが通常の方法です。特殊な目的がない限りこの設定は不要です。

#### 확률 [-1~1]
획득 성공 확률 (음수는 실패 시에만 평가됨)
- 획득 확률을 -1에서 1 사이의 소수로 설정합니다. 확률 판정에는 절대값이 사용됩니다.
- 값이 양수일 때는 액션 성공 시에만 판정되며, `1`이면 반드시 획득하고 `0.5`이면 50% 확률로 획득합니다.
- 값이 음수일 때는 액션 실패 시에만 판정되며, `-1`이면 반드시 획득하고 `-0.5`이면 50% 확률로 획득합니다.
- `0`인 경우 성공 시나 실패 시 모두 획득할 수 없습니다.
- 기본값은 `1`(성공 시 반드시 획득)입니다.

- 값이 양수일 때는 액션 성공 시에만 판정되며, `1`이면 반드시 획득하고 `0.5`이면 50% 확률로 획득합니다.
- 값이 음수일 때는 액션 실패 시에만 판정되며, `-1`이면 반드시 획득하고 `-0.5`이면 50% 확률로 획득합니다.
- `0`인 경우 성공 시나 실패 시 모두 획득할 수 없습니다.
- 기본값은 `1`(성공 시 반드시 획득)입니다.
