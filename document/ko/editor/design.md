
# 디자인
월드의 색상, 폰트 등 외형 설정
- 월드 표시 관련 설정입니다.
- 월드 전체 디자인에 대한 것이지만, 각 요소에 개별 설정이 있는 경우 그 설정이 우선시됩니다.
___

## 바 색상
바의 배경색이 되는 색상
- 바의 배경색으로 사용됩니다.
- 이 색상은 화면 아래의 배경색이 되므로, 선택 중인 행이나 스크롤 바의 색상도 이 색상을 바탕으로 만들어집니다.
___

## 글자 색상
글자와 배경색
- 글자 색상으로 사용됩니다.
- 배경 이미지를 설정하지 않으면, 이 색상을 바탕으로 한 그라데이션이 배경으로 적용됩니다.
- 배경색과의 명암 차이를 크게 주면 글자가 더 읽기 쉬워집니다.
___

## 그림자 색
바 그림자의 색상
- 바나 헤더에 드리워지는 그림자의 색상으로 사용됩니다.
- 바 색상보다 어두운 색으로 설정하면 자연스러운 그림자가 생깁니다.
___

## 배경 이미지
게임 전체 배경 이미지
- 게임 배경 이미지를 설정합니다.
- 이미지를 설정하지 않으면 글자 색상을 기반으로 한 그라데이션 배경이 적용됩니다.
