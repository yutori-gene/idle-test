
# 작업
조건을 충족하면 달성되는 미션
- 설정한 조건을 충족하면 달성으로 처리되며, 화면 위에 메시지가 표시됩니다.
- プレイヤーのミッションの一覧と、カテゴリのタスクの一覧に表示されます。
- 보상은 자동으로 지급되지 않습니다. 플레이어가 과제를 열고 획득 버튼을 누를 때 수령하게 됩니다.
- 보상을 수령하기 전까지는 목록의 막대에 리본이 표시되어 미수령 상태임을 나타냅니다.
- 獲得でカテゴリのレベル、アクションの実行回数、アイテムの所持数を変化させることができます。
- 첫 실행 시나 게임 오버 시 등, 특정 조건 이외의 시점에 발동시키고 싶은 항목은 기본 설정의 이벤트에서 설정합니다.
- [_event_](ko/editor/event)

## カテゴリ
タスクが所属するカテゴリのID
- このタスクを所属させるカテゴリのIDを指定します。
- 設定すると、プレイヤーのカテゴリの画面にタスクの一覧が追加され、ミッションの一覧でもカテゴリごとにまとめて表示されます。
- 空欄の場合はどのカテゴリにも属さず、ミッションの一覧の先頭にまとめて表示されます。
___

## 타이밍
작업 실행 시점 (`matched` 고정)
- 작업은 `matched`(설정한 조건을 충족했을 때)로 고정되어 있어 편집할 수 없습니다.
- 보상은 한 번만 받을 수 있으며, 한 번 받으면 그 이후로는 달성 상태로 고정됩니다.
- 그 외의 시점에 발동시키고 싶은 것은 기본 설정의 이벤트에서 설정합니다.
- [_event_](ko/editor/event)
___

## 초기 표시 상태
작업 아이콘의 초기 표시 상태 (달성 여부는 조건에 따라 결정되며, 이 설정에서는 달성되지 않습니다)
- タスクの達成条件はrequirementsで決まり、この項目は一覧アイコンの見た目のみに影響します。
- secreted: 全requirementsを満たすまでタスクの一覧に一切表示されません（達成自体は条件で起こります）。
- hidden・hinted: アイコンに斜線が付き未解放として表示されます。
- released: 斜線が消え解放済みとして表示されます。
- 一度達成したタスクは一覧から消えず、その後に条件を満たさなくなっても達成のまま表示されます。
___

## 조건
과제 달성 조건
- タスクを達成させる条件です。
- この条件を満たすと達成になり、報酬を受け取れるようになります。
- 一度達成すると、その後に条件を満たさなくなっても達成のままで、報酬もいつでも受け取れます。
- 条件を設定していないタスクは達成しません。
- requiringGroupを有効にすると、ここで指定するidの意味がカテゴリ・アクション・アイテム個別のIDからグループIDに変わります。
___

### 타입
조건으로 참조하는 요소의 종류

|타입|참조되는 값|
|-|-|
|カテゴリ|カテゴリのレベル|
|액션|액션 실행 횟수|
|아이템|아이템 보유 수|
___

### 요소의 ID
조건으로 참조하는 요소의 ID
___

### 값
요구사항에 필요한 값의 수
- 지정한 값 이상인 경우 조건을 만족합니다.
___

### 소비 확률[0-1]
아이템이 소모될 확률(0~1, 타입이 아이템인 경우에만 유효)
- 조건을 충족하고 액션이 실행되었을 때 아이템이 소비될 확률입니다.
- `1`이면 반드시 소비하고, `0.5`이면 50% 확률로 소비하며, `0`이면 소비하지 않습니다.
- 기본값은 `1`(반드시 소비)입니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

### 장비
아이템이 장비 상태일 것을 조건으로 할 것인지(타입이 아이템인 경우에만 유효)
- 활성화하면 아이템을 소지하고 있을 뿐만 아니라 장비가 장착되어 있는 것이 조건으로 요구사항이 됩니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

## 그룹 집계
조건의 id를 그룹 ID로 취급하여 소속 요소의 합계값으로 판정
- 활성화하면 조건(requirements)에 설정한 id는 기본 설정의 그룹 ID로 취급됩니다.
- Type이 카테고리인 조건은 해당 그룹에 속한 모든 카테고리의 레벨 합계로 판정합니다.
- Type이 액션인 조건은 해당 그룹에 속한 모든 액션의 실행 횟수 합계로 판정합니다.
- Type이 아이템인 조건은 해당 그룹에 속한 모든 아이템의 소지 수 합계로 판정합니다.
- 미해제(released 이외) 요소는 합계에 포함되지 않습니다.
- 아이템의 소비 확률(chance)과 장비 조건(equipment)은 무시되며, 소지 수를 소비하지도 않습니다. 판정에만 사용됩니다.
- 비활성화 시에는 기존과 같이 조건의 id는 개별 카테고리·액션·아이템의 ID로 취급됩니다.
___

## 보상
과제 달성 시 보상 설정
- 達成したタスクを開き、獲得のバーを押した時に受け取れる報酬です。
- カテゴリのレベル、アクションの実行回数、アイテムの所持数を変化させることができます。
- 数量にマイナスを設定することもできます。
- 報酬を設定していないタスクは獲得のバーが出ず、達成した時点で完了になります。
- 持てるアイテムの種類が上限に達している時は受け取れません。整理してから受け取り直します。
___

### 타입
획득하는 요소의 종류

|타입|획득할 수 있는 것들|
|-|-|
|カテゴリ|레벨(경험치 환산으로 합산)|
|액션|실행 횟수|
|아이템|보유 수|
___

### 요소의 ID
획득할 요소를 식별하는 ID
___

### 값
취득하는 값
- 마이너스 값을 설정하면 소지 수, 실행 횟수, 레벨이 감소합니다. 단, 0 아래로는 내려가지 않습니다.
- 아이템에 최대 소유 수(MAXIMUM)가 설정되어 있는 경우, 그 값을 초과하여 소유 수가 증가하지 않습니다.
- タイプがカテゴリの場合、設定した値がレベルに直接加算されます（1で1レベル、0.5で0.5レベル）。アクションの経験値設定で調整するのが通常の方法です。特殊な目的がない限りこの設定は不要です。
___

### 확률 [-1~1]
획득 성공 확률 (음수는 실패 시에만 평가됨)
- 획득 확률을 -1에서 1 사이의 소수로 설정합니다. 확률 판정에는 절대값이 사용됩니다.
- 값이 양수일 때는 액션 성공 시에만 판정되며, `1`이면 반드시 획득하고 `0.5`이면 50% 확률로 획득합니다.
- 값이 음수일 때는 액션 실패 시에만 판정되며, `-1`이면 반드시 획득하고 `-0.5`이면 50% 확률로 획득합니다.
- `0`인 경우 성공 시나 실패 시 모두 획득할 수 없습니다.
- 기본값은 `1`(성공 시 반드시 획득)입니다.
___
