
# 일반
언어, 레벨 설정 등의 기본적인 게임 설정
___

## 언어
월드 제작 당시의 언어
- 이 월드 에디터에서 사용할 언어를 설정합니다.
- 사용자가 게임을 시작할 때 가장 먼저 표시되는 언어입니다.
___

## 번역
다국어 번역을 준비할 것인가?
- 활성화된 경우 사용자가 원하는 언어로 플레이할 수 있습니다.
- 비활성화하면 언어 설정에서 선택한 언어로만 플레이할 수 있습니다.
- 번역을 활성화하려면 각 언어의 번역 데이터를 준비할 필요가 있습니다.
- [_translation_](ko/editor/translation)
___

## 최대 오프라인 꺼짐 시간[시간]
꺼짐 진행 시간 제한
- 꺼짐 시 최대 몇 시간 동안 진행할지 설정합니다.
- 예를 들어 6시간으로 설정한 경우, 6시간까지 오프라인으로 복귀하는 과정이 처리되지만, 그 이상의 시간을 두고 오프라인으로 복귀하더라도 오프라인 시간은 6시간으로 처리된다.
- 0시간으로 설정한 경우, 오프라인 복귀 시 프로세스 처리가 전혀 이루어지지 않습니다.
- 최대 값은 24시간입니다.
- [_category_](ko/editor/category)
___

## カテゴリの最大レベル
各カテゴリのレベル上限
- 各カテゴリの最大レベルを設定します。
- 이 레벨을 초과하여 경험치를 획득한 경우, 각 속성의 계산에는 여기서 설정한 최대 레벨이 사용됩니다.
- レベルのないカテゴリではこの値は関係ありません。
- [_category_](ko/editor/category)
___

## 잠금 기능
요구 사항을 충족할 때까지 항목 숨기기
- 有効の場合、カテゴリ・アクション・アイテムは一度も使用・所持したことがなく、かつrequirementsを満たしていない間は非表示になります。
- 비활성화하면 모든 항목이 처음부터 표시되지만, 요구 사항을 충족할 때까지 실행 및 장비 장착이 불가능합니다.
- [_category_](ko/editor/category)
- [_action_](ko/editor/action)
- [_item_](ko/editor/item)

## 통화
게임 내에서 사용하는 화폐(코인) 설정
- 게임 내에서 사용되는 화폐를 설정합니다.
- 통화는 여러 개를 정의할 수 있으며, 각각을 정보(ID·이름·아이콘·색상 등)로 설정합니다.
- 통화는 아이템을 사고팔거나, 인벤토리 용량을 확장하는 데 사용됩니다.
- 첫 번째 통화가 기본 통화로 간주되며, 아이템이나 용량에서 통화 ID(`coinId`)가 지정되지 않은 경우에 사용됩니다.
- [_information_](ko/editor/information)
- [_item_](ko/editor/item)
___

## 용량
인벤토리 용량 설정
- 플레이어가 소지할 수 있는 아이템의 종류 수에 대한 상한선을 관리합니다.
- 각 아이템의 소유 개수가 아닌 소유한 아이템의 종류 수로 관리된다.
- `initialCount`를 0으로 설정하면 용량이 무제한이 됩니다.
- 조건이나 보상에서 용량의 아이템을 참조할 때는 여기서 설정한 ID를 사용하세요.
- [_item_](ko/editor/item)
___

### [_인포메이션_](ko/editor/information)
___

### 초기 값 [개].
초기 인벤토리 용량(소지할 수 있는 아이템의 종류 수)
- 게임 시작 시 초기 용량(소지할 수 있는 아이템의 종류 수)입니다.
- `0`으로 설정하면 용량이 무제한이 됩니다.
___

### 기본 가격[코인]
용량 1개 증설에 대한 초기 가격
- 인벤토리 용량을 1슬롯 늘릴 수 있는 기본 가격(코인)입니다.
- 실제 가격은 '기본 가격 × 증가율 ^ 구매 횟수'로 계산됩니다.
- 예시: 기본 가격 100, 증가율 1.2의 경우 1차 100코인, 2차 120코인, 3차 144코인이 됩니다.
___

### 증가율[배]
용량 확장 비용 증가율
- n번째 구매 시 용량 확장 비용이 얼마나 증가하는지를 나타내는 배율입니다.
- `1.0`이면 항상 같은 가격이고, `1.2`이면 구매할 때마다 20%씩 비싸집니다.
- 계산식 : 기본 가격 × 증가율 ^ 구매 횟수

|증가율|1번째 추가|5번째 증가|10번째 증가|100번째 증가|1000번째 증가|
|-|-|-|-|-|-|
|1.00|x1.00|x1.00|x1.00|x1.00|x1.00|
|1.05|x1.00|x1.22|x1.63|x131.50|x1.7×10²⁰|
|1.10|x1.00|x1.61|x2.59|x1.4×10⁴|x2.7×10⁴¹|
|1.20|x1.00|x2.49|x6.19|x8.3×10⁷|x8.3×10⁷⁹⁹|
|1.50|x1.00|x5.06|x57.67|X1.9×10¹⁷|x7.0×10¹⁷⁶⁶|
___

### 통화 ID
용량 확장에 사용되는 통화의 ID
- 인벤토리 용량 확장 비용으로 사용할 통화(coins)의 ID를 지정합니다.
- 공란인 경우 기본 통화(coins의 맨 앞)가 사용됩니다.
___

### 구매 한도 [회]
용량을 구매할 수 있는 최대 횟수
- 통화로 용량을 구매할 수 있는 횟수의 상한선입니다.
- `0`으로 설정하면 무제한으로 구매할 수 있습니다.
- `-1`로 설정하면 구매할 수 없게 됩니다.
- 보상으로 인한 용량 증가는 이 상한선의 적용 대상이 아닙니다.
___

## 큐
액션 연속 실행 대기열의 슬롯 수 설정
- 액션을 연속으로 실행하기 위한 대기열의 슬롯 수를 관리합니다.
- 대기열은 실행 중인 액션을 포함하며, 맨 앞에 있는 액션이 실행됩니다. 슬롯이 `1`일 때는 실행 중인 액션만 들어가고 대기는 둘 수 없습니다.
- 슬롯 수는 용량과 마찬가지로 화폐로 구매할 수 있을 뿐만 아니라, 액션이나 이벤트 보상을 통해 대기열의 특정 아이템을 지정하여 늘릴 수도 있습니다.
- 조건이나 보상으로 큐의 아이템을 참조할 때는 여기에서 설정한 ID를 사용하십시오.
- [_item_](ko/editor/item)
___

### [_인포메이션_](ko/editor/information)
___

### 초기 값 [개].
게임 시작 시 연속 실행 가능한 수
- 게임 시작 시의 대기열 슬롯 수입니다.
- 최소값은 `1`입니다(실행 중인 액션이 슬롯 하나를 사용하며, 용량과 같이 `0`=무제한으로 처리되는 경우는 없습니다).
___

### 기본 가격[코인]
슬롯을 하나 추가하기 위한 초기 가격
- 연속 실행 횟수를 1회 늘리기 위한 기본 가격(코인)입니다.
- 실제 가격은 '기본 가격 × 증가율 ^ 구매 횟수'로 계산됩니다.
- 예시: 기본 가격 100, 증가율 1.2의 경우 1차 100코인, 2차 120코인, 3차 144코인이 됩니다.
___

### 증가율[배]
프레임 확장 비용의 증가율
- n번째 구매 시 슬롯 확장 비용이 얼마나 증가하는지를 나타내는 배율입니다.
- `1.0`이면 항상 같은 가격이고, `1.2`이면 구매할 때마다 20%씩 비싸집니다.
- 계산식 : 기본 가격 × 증가율 ^ 구매 횟수
___

### 통화 ID
프레임 확장에 사용되는 통화의 ID
- 연속 실행 슬롯 확장 비용에 사용할 통화(coins)의 ID를 지정합니다.
- 공란인 경우 기본 통화(coins의 맨 앞)가 사용됩니다.
___

### 구매 한도 [회]
권한을 구매할 수 있는 최대 횟수
- 통화로 연속 실행 횟수를 구매할 수 있는 최대 횟수입니다.
- `0`으로 설정하면 무제한으로 구매할 수 있습니다.
- `-1`로 설정하면 구매할 수 없게 됩니다.

## 경험치 상승률[배]
레벨업 난이도 증가율
- カテゴリのレベルが上がるにつれて、次のレベルになるのに必要な経験値の上昇率です。
- 이 값을 위로 올리면 난이도가 높아집니다.
- 다음 레벨로 올라가기 위해 필요한 경험치는 (경험치 상승률)^(현재 레벨 - 1)입니다.

## 액션 레벨 제한
액션의 실행에 동일 속성 액션의 실행 횟수를 요구함
- 활성화하면 각 액션의 실행 조건에 동일한 속성을 가진 액션의 실행 횟수가 자동으로 추가됩니다.
- 필요한 횟수는 액션의 레벨 값과 동일합니다.
- 属性が設定されていない場合は、所属するカテゴリのIDが使用されます。
___

## 속성 배율[배]
레벨 차이 10마다 속성이 몇 배가 되는지
- 카테고리의 레벨과 액션의 레벨 차이가 `10`씩 벌어질 때마다 속성이 몇 배가 되는지를 설정합니다.
- 배율은 (속성 배율)^(레벨 차이÷10)로 계산됩니다. 레벨 차이가 `0`일 때는 `1`배가 되며, 액션에 설정한 값이 그대로 사용됩니다.
- 공격과 경험치는 이 배율만큼 증가하고, 방어(받는 피해)와 민첩성(소요 시간)은 같은 배율만큼 감소합니다.
- 명중, 회피, 성공 확률, 회복량은 `0`〜`100`% 범위에 들어가는 값이므로 성립하는 쪽과 성립하지 않는 쪽의 비율에 배율이 적용됩니다. `0`%와 `100`%는 변하지 않으며, 중간 값이 `100`%를 넘는 일도 없습니다.
- 방어, 회피, 민첩성은 배율 효과가 절반입니다(레벨 차이 `20`이 다른 속성의 레벨 차이 `10`에 해당합니다). 방어와 회피는 피격 확률과 받는 피해에 이중으로 적용되고, 민첩성은 실행 횟수로서 다른 모든 속성에 적용되므로 효과를 약하게 하여 균형을 맞추고 있습니다.
- 기준은 (경험치 상승률)의 `6.7`제곱입니다. 이를 넘으면 레벨이 오를수록 레벨업이 빨라지고, 밑돌수록 후반 레벨업에 시간이 더 걸립니다.
- `1`로 설정하면 레벨 차이의 영향이 없어집니다. 값을 크게 하면 레벨 차이에 따른 유불리가 급격해집니다.

|속성 배율|레벨 차이 -20|레벨 차이 -10|레벨 차이 0|레벨 차이 +10|레벨 차이 +20|
|-|-|-|-|-|-|
|`1`|`x1.00`|`x1.00`|`x1.00`|`x1.00`|`x1.00`|
|`1.5`|`x0.44`|`x0.67`|`x1.00`|`x1.50`|`x2.25`|
|`2`|`x0.25`|`x0.50`|`x1.00`|`x2.00`|`x4.00`|
|`3`|`x0.11`|`x0.33`|`x1.00`|`x3.00`|`x9.00`|
