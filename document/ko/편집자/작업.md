
# 작업
조건을 충족하면 달성되는 미션
- 설정한 조건을 충족하면 달성으로 처리되며, 화면 위에 메시지가 표시됩니다.
- 플레이어의 미션 목록과 카테고리별 과제 목록에 표시됩니다.
- 보상은 자동으로 지급되지 않습니다. 플레이어가 과제를 열고 획득 버튼을 누를 때 수령하게 됩니다.
- 보상을 수령하기 전까지는 목록의 막대에 리본이 표시되어 미수령 상태임을 나타냅니다.
- 획득을 통해 카테고리의 레벨, 액션 실행 횟수, 아이템 소지 수를 변경할 수 있습니다.
- 첫 실행 시나 게임 오버 시 등, 특정 조건 이외의 시점에 발동시키고 싶은 항목은 기본 설정의 이벤트에서 설정합니다.
- [_event_](ko/편집자/이벤트)

## 카테고리
작업이 속한 카테고리의 ID
- 이 작업을 할당할 카테고리의 ID를 지정합니다.
- 설정하면 플레이어 카테고리 화면에 작업 목록이 추가되며, 미션 목록에서도 카테고리별로 정리되어 표시됩니다.
- 공란인 경우 어떤 카테고리에도 속하지 않으며, 미션 목록의 맨 앞에 한꺼번에 표시됩니다.
___

## 타이밍
작업 실행 시점 (`matched` 고정)
- 작업은 `matched`(설정한 조건을 충족했을 때)로 고정되어 있어 편집할 수 없습니다.
- 보상은 한 번만 받을 수 있으며, 한 번 받으면 그 이후로는 달성 상태로 고정됩니다.
- 그 외의 시점에 발동시키고 싶은 것은 기본 설정의 이벤트에서 설정합니다.
- [_event_](ko/편집자/이벤트)
___

## 초기 표시 상태
작업 아이콘의 초기 표시 상태 (달성 여부는 조건에 따라 결정되며, 이 설정에서는 달성되지 않습니다)
- 작업의 달성 조건은 requirements에서 결정되며, 이 항목은 목록 아이콘의 모양에만 영향을 미칩니다.
- secreted: 모든 요구 사항을 충족할 때까지 작업 목록에 전혀 표시되지 않습니다(달성 자체는 조건에 따라 발생합니다).
- hidden・hinted: 아이콘에 가로줄이 표시되어 잠금 상태로 나타납니다.
- released: 사선이 사라지고 '해제됨'으로 표시됩니다.
- 한 번 완료한 작업은 목록에서 사라지지 않습니다. 미완료 상태로 뒤로 돌아간 경우 아이콘에 가로줄이 표시됩니다.
___

## 조건
과제 달성 조건
- 과제를 달성하기 위한 조건입니다.
- 이 조건을 충족하면 달성으로 인정되어 보상을 받을 수 있게 됩니다.
- 보상을 받기 전에 조건을 충족하지 못하게 되면, 미달성 상태로 뒤로 돌아가 보상을 받을 수 없게 됩니다. 다시 조건을 충족하면 보상을 받을 수 있습니다.
- 조건이 설정되지 않은 작업은 완료되지 않습니다.
___

### 타입
조건으로 참조하는 요소의 종류

|타입|참조되는 값|
|-|-|
|카테고리|카테고리 레벨|
|액션|액션 실행 횟수|
|아이템|아이템 보유 수|
___

### 요소의 ID
조건으로 참조하는 요소의 ID
___

### 값
요구사항에 필요한 값의 수
- 지정한 값 이상인 경우 조건을 만족합니다.
___

### 소비 확률[0-1]
아이템이 소모될 확률(0~1, 타입이 아이템인 경우에만 유효)
- 조건을 충족하고 액션이 실행되었을 때 아이템이 소비될 확률입니다.
- 1`이면 반드시 소비, `0.5`이면 50% 확률로 소비, `0`이면 소비하지 않습니다.
- 기본값은 `1`(반드시 소비)입니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

### 장비
아이템이 장비 상태일 것을 조건으로 할 것인지(타입이 아이템인 경우에만 유효)
- 활성화하면 아이템을 소지하고 있을 뿐만 아니라 장비가 장착되어 있는 것이 조건으로 요구사항이 됩니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

## 보상
과제 달성 시 보상 설정
- 완료한 과제를 열고, 획득 바를 누르면 받을 수 있는 보상입니다.
- 카테고리 레벨, 액션 실행 횟수, 아이템 소지 수를 변경할 수 있습니다.
- 수량에 마이너스 값을 설정할 수도 있습니다.
- 보상이 설정되지 않은 과제는 획득 바가 표시되지 않으며, 달성하는 즉시 완료됩니다.
___

### 타입
획득하는 요소의 종류

|타입|획득할 수 있는 것들|
|-|-|
|카테고리|레벨(경험치 환산으로 합산)|
|액션|실행 횟수|
|아이템|보유 수|
___

### 요소의 ID
획득할 요소를 식별하는 ID
___

### 값
취득하는 값
- 마이너스 값을 설정하면 소지 수, 실행 횟수, 레벨이 감소합니다. 단, 0 아래로는 내려가지 않습니다.
- 아이템에 최대 소유 수(MAXIMUM)가 설정되어 있는 경우, 그 값을 초과하여 소유 수가 증가하지 않습니다.
- 타입이 카테고리의 경우 설정한 값이 레벨에 직접 추가됩니다(1이면 1레벨, 0.5이면 0.5레벨). 액션의 경험치 설정에서 조정하는 것이 일반적인 방법입니다. 특별한 목적이 없는 한 이 설정은 불필요합니다.
___

### 확률 [-1~1]
획득 성공 확률 (음수는 실패 시에만 평가됨)
- 획득 확률을 -1에서 1 사이의 소수로 설정합니다. 확률 판정에는 절대값이 사용됩니다.
- 값이 양수일 경우, 액션 성공 시에만 평가되며, `1`일 때는 반드시 획득하고, `0.5`일 때는 50%의 확률로 획득합니다.
- 값이 음수일 때는 액션 실패 시에만 평가되며, `-1`일 경우 반드시 획득하고, `-0.5`일 경우 50%의 확률로 획득합니다.
- `0`인 경우 성공 시나 실패 시 모두 획득할 수 없습니다.
- 기본값은 `1`(성공 시 반드시 획득)입니다.
___
