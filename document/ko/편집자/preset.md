
# 프리셋
시스템 요소 표시 사용자 정의하기
- 게임 엔진(플레이어)에 미리 내장된 UI 텍스트와 아이콘을 교체합니다.
- ID가 기존 프리셋과 일치하는 ID로만 대체됩니다.
- 설정한 항목만 대체됩니다. 예를 들어 아이콘만 설정한 경우, 이름이나 색상 등 다른 항목은 원래의 항목이 사용됩니다.
___

## 식별 ID
요소를 식별하기 위한 고유 ID
- 각 요소를 고유하게 식별하기 위한 ID입니다.
- 에디터에서 해당 요소를 판별하기 위한 문자열입니다.
- 예를 들어, 액션이 완료되면 어떤 아이템을 획득할 것인지를 ID로 지정합니다.

!> 한번 설정한 ID는 게임을 배포한 후에는 변경하지 마십시오. 변경하면 기존 게임 데이터와 일치하지 않아 정상적으로 작동하지 않습니다.
___

### 표시되는 이름
ID에서 자동 생성되는 표시 이름
- 사용할 수 있는 문자는 알파벳, 하이픈, 숫자의 조합입니다.
- 이름이 설정되지 않은 경우 각 단어의 첫 글자는 대문자로, 하이픈은 공백으로 대체되어 이름에 자동으로 설정됩니다.
- 영어 이외의 언어는 이름 항목을 별도로 설정할 필요가 있습니다.
___

#### 예시
ID 변환의 실례
- ID를 `stylish-strong-axe`로 설정하면 이름은 `Stylish Strong Axe`가 된다.
___

### 중복 없음
동일 타입 내 ID 중복 금지
- 요소 식별에 사용되므로 카테고리, 액션, 아이템, 이벤트, 프리셋 타입 내에서 중복되지 않아야 합니다.
- 다른 타입에 동일한 ID가 있는 것은 문제가 되지 않습니다.
- [_type_](ko/편집자/유형)
___

## 이름
요소의 표시되는 이름
- 게임에서 표시되는 요소의 이름입니다.
- 영어 이외의 언어도 입력할 수 있습니다.
- 다른 요소와 중복되는 이름도 괜찮습니다.
- 너무 길면 플레이 중 표시에서 튀어나온 부분은 `...`로 생략됩니다.
___

### ID에서 자동 변환
ID에서 이름 자동 생성 기능
- 비어있는 경우, ID를 기준으로 자동으로 표시됩니다. 자세한 내용은 이전 항목을 참고하세요.
___

## 설명문
요소에 대한 자세한 설명
- 게임에 표시되는 요소에 대한 설명입니다.
- 영어 이외의 언어도 입력할 수 있습니다. 긴 문장도 모두 표시됩니다.
- 설명이 없음은 비워둡니다.
___

## 아이콘
요소를 나타내는 아이콘 설정
- 아이콘은 이미지, Iconify, 이모티콘 중 하나를 설정할 수 있다.
- Iconify는 다양한 종류의 아이콘을 제공하는 서비스입니다.
- 이 중 여러 개를 설정한 경우, 이미지, Iconify, 이모티콘 순으로 우선순위를 지정해 표시합니다.
___

### 이미지
임의의 이미지 파일 사용
- 요소를 나타내는 이미지입니다.
- 파일 크기가 클 경우 자동으로 크기가 조정됩니다.
- Iconify 또는 이모티콘을 설정한 경우에는 불필요합니다.
___

#### 파일 유형
지원되는 이미지 파일 형식
- 브라우저에서 볼 수 있는 일반적인 종류를 사용할 수 있습니다.
- JPEG, PNG, GIF, WebP, SVG 등.
___

### Iconify
Iconify 아이콘 세트 사용
- 요소를 나타내는 아이콘입니다.
- Iconify는 다양한 종류의 아이콘을 제공하는 서비스입니다.
- 이미지를 설정한 경우 해당 이미지가 우선적으로 표시됩니다.
___

#### Iconify
Iconify에서 아이콘 선택 방법
- 표시할 수 있는 아이콘은 `Iconify`에서 검색해 주세요.
- 아이콘 검색을 통해 최적의 아이콘을 바로 찾을 수 있습니다.
- 아이콘을 선택하면 `game-icons:sword-wound` 등 해당 아이콘의 식별자(아이콘 세트의 종류`:`아이콘의 이름)가 표시되므로, 이를 그대로 이 아이콘 항목에 붙여 넣으시면 됩니다.
![iconify-selection.png](../../resources/iconify-selection.png)
- [_iconify_](https://icon-sets.iconify.design)
___

### 이모티콘
이모티콘으로 아이콘 표시
- 이모티콘을 아이콘으로 표시합니다.
- 문자에서 이모티콘으로 변환하여 빠르게 설정할 수 있습니다.
- 이모티콘은 유니코드 이모티콘을 그대로 입력하세요.
- 실행 환경에 도입된 이모티콘을 사용하기 때문에 사용자에 따라 다소 다르게 표시될 수 있습니다.
- Iconify에서는 각 환경에 구애받지 않는 이모티콘을 설정할 수 있습니다.
- 이모티콘 이외의 문자를 표시할 수 있지만, 문자 수가 많으면 표시가 깨질 수 있습니다.
- 예를 들어 `🗡️`, `⚔️` 등의 이모티콘을 입력합니다.
___

## 색상
요소의 표시 색상 설정
- 요소의 색상으로 요소의 아이콘과 배경색에 적용된다.
- 에디터의 색상 선택기에서 선택합니다.
___

### 상위 요소로부터의 상속
상위 요소의 색상 설정 이어받기
- 비어 있는 경우 상위 요소에서 설정된 색상을 이어받습니다.
- 각 요소의 타입별 계층 구조는 아래와 같습니다.
- 예를 들어, 액션에 개별 색상이 설정되어 있는 경우 해당 색상이 사용되며, 액션에 개별 색상이 설정되어 있지 않은 경우 카테고리 또는 월드의 색상이 사용됩니다.
```
world
├── category
├── action
├── item
├── group
├── event
└── preset
```
- [_type_](ko/편집자/유형)
