
# 액션
채집, 제작, 전투 등의 행동 요소
- 채집, 제작, 매매, 전투 등 행동을 나타내는 요소입니다.
- 행동을 할 때마다 경험치를 얻고 레벨이 올라갑니다.
- 행동할 때마다 아이템을 소비하거나 획득할 수 있도록 설정할 수 있습니다.
- 행동 패턴에는 몇 가지 유형이 있습니다.
___

## 카테고리
액션이 속하는 카테고리의 ID
- 이 액션이 속한 카테고리의 ID를 지정합니다.
___

## 속성
액션 별 속성 카테고리
- 개별 속성(카테고리)을 설정할 수 있습니다.
- 비어있는 경우 해당 카테고리를 이어받습니다.
- 예를 들어, 마왕성이라는 카테고리에 속하는 액션에 마법이라는 속성을 개별적으로 설정하면, 액션 완료 시간이나 데미지에는 마법 카테고리의 레벨과 속성이 계산되어 적용된다.
- [_category_](ko/편집자/카테고리)
___

## 그룹
액션의 표시 그룹 분류
- 기본 설정에서 설정한 그룹 중 하나를 맞춰주세요.
- 설정한 그룹 순서대로 액션 목록이 표시됩니다.
- [_general_](ko/편집자/일반)
___

## 초기 해제 상태
요소의 초기 표시·해제 상태 (발동 조건을 충족하면 자동으로 위 상태로 전환됨)
- secreted: 모든 요구 사항을 충족할 때까지 UI에 전혀 표시되지 않습니다(힌트에도 나타나지 않으며, 요구 사항/보상 목록에서도 가려집니다).
- hidden: 어떤 해제 요소에서도 참조되지 않고 요건도 충족되지 않은 동안에는 완전히 숨겨집니다(이름도 회색으로 표시되며 조작할 수 없음).
- hinted(기본값): 이름만 미리 표시되지만, 잠금이 해제될 때까지는 조작할 수 없습니다.
- released: 조건에 관계없이 처음부터 해제되어 조작할 수 있습니다(이전 ‘처음부터 표시’).
___

## 레벨
액션 난이도 레벨
- 액션의 난이도를 레벨로 표시합니다.
- 실행 시 플레이어의 레벨과 비교하여 각 속성을 계산합니다.
- 예를 들어 자신의 레벨보다 높은 액션을 수행하면 성공률이 낮아지는 등의 영향이 있습니다.
- 플레이어의 레벨이 이 값보다 작아도 조건만 충족하면 실행할 수 있습니다.
- [_property_](ko/편집자/property)

## 소요 시간 [초].
액션 실행에 소요되는 표준 시간
- 액션을 한 번 수행하는 데 필요한 표준 시간(초)입니다.
- 스태미나` 타입의 경우, 1턴(서로의 스태미나를 1회 깎는 데 걸리는 시간 간격입니다.
- 속성 계산에 따라 실제 실행 시에는 변동이 있을 수 있습니다.
- [_property_](ko/편집자/property)
___

## 경험치[100으로 다음 레벨로 올라갑니다.]
액션 성공 시 획득하는 경험치
- 액션을 한 번 실행하고 성공했을 때 획득하는 표준 경험치이며, 100으로 1레벨 분량의 경험치입니다.
- 전투의 경우 상대에게 승리할 때 획득하기 때문에 많이 설정하는 것이 좋습니다.
- 속성 계산에 따라 실제 실행 시에는 변동이 있을 수 있습니다.
- [_property_](ko/편집자/property)
___

## 성공 확률[0-1].
액션 완료 시 성공 확률
- 액션 완료 시 성공할 확률입니다.
- 1`이면 항상 성공, `0`이면 항상 실패입니다.
- 실패 시 소비 아이템은 소모되지만, 보상이나 경험치는 얻을 수 없습니다.
- 속성 계산에 따라 실제 실행 시에는 변동이 있을 수 있습니다.
___

## 최대 실행 횟수[회]
액션을 완료할 수 있는 최대 횟수
- 액션이 성공적으로 완료될 수 있는 횟수의 상한선입니다.
- 0`의 경우 무제한입니다.
- 위 한도에 도달하면 액션을 실행할 수 없게 됩니다.

## 진행 타입
액션 실행 타입
- 4가지 종류가 있습니다.

|타입|동작 내용|스태미나|예시|
|-|-|-|-|
|`persistent`|액션이 지속적으로 반복적으로 실행되는 타입으로, 한 번 완료할 때마다 경험치와 보상을 얻는다.|관련 없음|벌목, 채광, 낚시|
|`single`|한 번의 액션을 실행합니다. 중간에 중단하면 진행 상황이 저장되어 다음부터 계속 진행할 수 있습니다. 완료되면 사용자는 확인 액션을 눌러 결과를 받아볼 수 있습니다.|관련 없음|보물상자 열기, 독서를 통한 기술 습득|
|`snap`|액션이 즉시 실행되는 타입입니다. 시간 경과 없음으로 즉시 완료됩니다.|관련 없음|물물교환, 아이템의 사용|
|`stamina`|소요 시간마다 플레이어와 상대방의 스태미나가 각각 감소합니다. 상대방의 스태미나가 소진되면 경험치와 보상을 얻게 됩니다. 플레이어의 스태미나가 다 떨어지면 게임 오버가 되어 실행 중인 모든 액션이 중단됩니다.|관련 있음|전투, 위험한 작업|
___
