
# 번역
게임 내 텍스트를 다른 언어로 번역하기 위한 설정
- 번역할 텍스트를 설정합니다.
- 번역 설정을 활성화하면 다국어 설정이 가능합니다.
- 번역이 유효하지 않은 경우, 개발 중에 기재한 내용이 그대로 표시됩니다.
- 공개 전 개발 중인 경우 번역 설정 및 언어 전환은 불가능합니다.
___

## 번역 활성화
번역 기능 켜짐 및 꺼짐 설정
- 번역 설정을 활성화하면 다국어 설정이 가능합니다.
- 공개 전 개발 중인 경우 번역이 활성화되지 않습니다. 공개 후 언어 전환이 가능해집니다.
- 번역을 활성화하면 10가지 언어에 대응하게 되며, 모든 언어에 대한 번역 데이터를 준비할 필요가 있습니다. 일부 언어만 활성화할 수는 없습니다.
- 사용자가 게임을 시작하면 개발 시 사용된 언어가 먼저 표시된다. 이후 원하는 언어로 변경할 수 있습니다.
- 번역 작업은 번거롭지만, 많은 사람들이 즐길 수 있게 됩니다.
___

## 언어 파일
번역 데이터 JSON 파일
- 게임 데이터를 공개 설정으로 출력하면 출력된 폴더 내 `translations/world`에 번역용 JSON 파일이 생성됩니다.
- 폴더 내에 각 언어의 번역용 JSON 파일이 배치되어 있습니다. 내용에는 번역되지 않은 데이터가 포함되어 있습니다.
- 내용은 각 타입 안에 ID가 있습니다. 그리고 그 안에 이름과 설명이 있습니다.
- 모든 이름과 설명에 대해 번역을 하고 저장할 필요가 있습니다.
___

## 번역 작업
번역 데이터 편집 작업
- 모든 번역 파일에는 개발 당시의 언어 데이터가 포함되어 있습니다.
- 개발 당시 언어가 아닌 다른 언어의 파일에 대한 번역 작업이 필요합니다.
___

### AI
AI를 활용한 번역
- ChatGPT, Copilot, Claude 등의 AI를 활용하여 번역합니다.
- 한 번에 번역할 수 있고, 어느 정도 퀄리티 있는 번역이 가능합니다.
- 완벽한 번역이 될 수 없음, 특히 전문용어나 고유명사 번역에는 주의가 필요합니다.
- 번역량에 따라 AI를 이용하기 위해서는 비용이 발생할 수 있습니다.
- 중간에 AI의 번역 진행이 중단된 경우 '계속 진행'을 지시하면 어떻게든 되는 경우가 있습니다. (어쩔 수 없는 경우도 있음).
___

#### 프롬프트 예시
AI에 대한 번역 지시 예시
- 프롬프트 예시: 업로드한 JSON 데이터의 `name`과 `explanation` 값을 영어에서 일본어로 번역해 주세요. 그 외의 부분은 수정할 부분이 없음.
___

#### GPT 이용
ChatGPT의 GPT를 이용한 번역
- ChatGPT에서 제공하는 GPT 라이브러리에서 제공하는 JSON Language Translator를 이용하면 JSON 번역을 쉽게 할 수 있습니다.
- JSON의 구조가 유지된 채로 번역됩니다.
- ChatGPT 이외의 AI 서비스에서도 비슷한 기능을 제공하는 경우가 있습니다.
___

### 번역 서비스
번역 서비스 이용
- DeepL, 구글 번역 등 온라인 서비스를 이용해 번역한다.
- AI 번역보다 높은 품질의 번역을 기대할 수 있지만, 번역량에 따라 요금이 부과됩니다.
- JSON 파일을 그대로 번역 서비스에서 번역할 수 없기 때문에 프로그램을 만들어서 사용할 필요가 있습니다.
- 유료이지만 JSON 데이터 그대로 번역해주는 서비스도 있는 것 같습니다. (doctranslator.com 등)
___

### 수동
수동 번역
- 번역 파일을 텍스트 편집기로 열고 각 언어로 번역한 내용을 입력합니다. 매우 번거롭지만 원하는 대로 번역이 가능합니다.
