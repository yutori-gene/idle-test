
# 조건
요소의 사용 및 표시에 필요한 요구사항 설정
- 카테고리, 액션, 아이템별 각 요소에 설정하는 조건입니다.
- 설정한 조건이 모두 충족되지 않으면 표에 표시된 조작이 불가능합니다.
- 잠금 기능이 활성화된 경우, 조건을 충족할 때까지 요소 자체가 숨겨집니다.

|설정 위치|조건이 없으면 할 수 없는 것들|
|-|-|
|카테고리|카테고리 내 모든 액션의 실행 및 아이템 조작|
|액션|액션 실행|
|아이템|아이템 조작 (장비 등)|
- [_type_](ko/편집자/유형)
___

## 타입
조건으로 참조하는 요소의 종류

|타입|참조되는 값|
|-|-|
|카테고리|카테고리 레벨|
|액션|액션 실행 횟수|
|아이템|아이템 보유 수|
___

## 요소의 ID
조건으로 참조하는 요소의 ID
___

## 값
요구사항에 필요한 값의 수
- 지정한 값 이상인 경우 조건을 만족합니다.
___

## 소비 확률[0-1]
아이템이 소모될 확률(0~1, 타입이 아이템인 경우에만 유효)
- 조건을 충족하고 액션이 실행되었을 때 아이템이 소비될 확률입니다.
- 1`이면 반드시 소비, `0.5`이면 50% 확률로 소비, `0`이면 소비하지 않습니다.
- 기본값은 `1`(반드시 소비)입니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
___

## 장비
아이템이 장비 상태일 것을 조건으로 할 것인지(타입이 아이템인 경우에만 유효)
- 활성화하면 아이템을 소지하고 있을 뿐만 아니라 장비가 장착되어 있는 것이 조건으로 요구사항이 됩니다.
- 타입이 아이템이 아닌 경우 유효하지 않습니다.
