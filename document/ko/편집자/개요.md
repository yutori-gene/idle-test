
# 개요
월드 기본 정보 및 작가 정보
- 월드의 내용을 설명하는 항목입니다.
- 사용자가 월드 선택 시 쉽게 이해할 수 있도록 설정해야 합니다.
- 이러한 설정은 월드의 동작에 영향을 미치지 않습니다.
___

## [_인포메이션_](ko/편집자/정보)
___

## 버전
월드의 버전 번호
- 임의의 값(정수 또는 소수점)을 입력하세요.
- 일반적으로 정수 부분은 메이저 버전, 소수 부분은 마이너 버전을 나타낸다.
___

## 작가 이름
월드 작가 이름
- 아이디나 닉네임을 입력해 주세요.
___

## 홈페이지
작가 웹사이트 URL
- 자신의 홈페이지나 SNS가 있다면 해당 URL을 입력해주세요.
- 플레이어는 링크를 통해 이 URL을 확인할 수 있습니다.
- 해당사항이 없음은 비워두세요.
___

## URL
게임 URL
- 이 월드의 게임을 배치할 URL을 입력하세요.
- index.html과 같은 맨 위의 URL을 도메인을 포함하여 입력합니다.
- 적절한 URL이 기재되어 있으면 PWA로 동작합니다.
- PWA는 설치만 하면 꺼짐 상태에서도 앱처럼 작동해 오프라인에서도 플레이할 수 있는 기능이다.
___

## 예상 플레이 시간
월드 플레이 완료까지 소요되는 예상 시간
- 월드 플레이를 완료하는 데 필요한 예상 플레이 시간입니다.
- 플레이어가 플레이할 때 참고할 수 있습니다.
- 어디까지가 월드의 완성인지에 대한 명확한 정의가 없는 참고용 시간일 뿐입니다.
___

### 값
플레이 시간의 값
___

### 단위
시간 단위(시간, 분 등)
