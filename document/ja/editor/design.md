
# デザイン
ワールドの色やフォントなどの見た目設定
- ワールドの表示についての設定です。
- ワールド全体のデザインについてですが、各要素で個別の設定がある場合はそれが優先されます。
___

## 主色
ワールドの主要カラー
- バーの色として使用されます。
- バーの影にはこれの反対色が使用されます。
___

## 補助色
背景と文字の補助カラー
- 背景色と文字色として使用される色です。
- 主色に近い色合いにすると馴染みます。
___

## 背景画像
ゲーム全体の背景画像
- ゲーム背景画像を設定します。
- 画像を設定しない場合は、補助色を元にしたグラデーションの背景となります。
