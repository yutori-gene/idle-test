
# カテゴリ
Uma compilação de vários elementos.
- カテゴリはアクション・アイテム・プロパティ・スキル・タスクをまとめた単位
- レベルはアクションの実行で得られる経験値によって上がる
- 進捗と装備のバーは長押しで切り替えられる
- 装備枠はグループごとに1つ用意される
___

## Tarefa
カテゴリ内のタスクの一覧
- タスクは、条件を満たすと達成となるイベント。報酬は自分で受け取る
- 報酬をまだ受け取っていないタスクにはリボンが付く。開いて受け取るを押す
- 所持できる種類数が上限のあいだは報酬を受け取れない。空きを作ってから受け取り直す
