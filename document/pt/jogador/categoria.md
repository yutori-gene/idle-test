
# Categoria.
Uma compilação de vários elementos.
- Esse é um elemento que reúne Ações e Itens.
___

## Tarefa
Lista de tarefas da categoria
- Esta é a lista de tarefas atribuídas a esta categoria.
- Ao selecionar uma tarefa, você poderá verificar as condições de conclusão e a recompensa.
- As tarefas cuja recompensa ainda não foi recebida são marcadas com uma fita. Basta selecioná-las e clicar em “Receber” para obtê-la.
- Se não houver nenhuma tarefa na categoria, ela não será exibida.
