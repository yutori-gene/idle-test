
# componente
Partes comuns
- Os componentes comuns usados em cada configuração de local são extraídos e manipulados.
- Os componentes usados em todas essas áreas são comuns, mas nada é usado em alguns dos itens.

|componente|説明|
|-|-|
|[_informações_](pt/editor/informações)|Configuração de informações básicas sobre o elemento (ID, nome, ícone, cor, etc.)|
|[_requisito_](pt/editor/requisito)|Configuração dos requisitos necessários para o uso e exibição de elementos.|
|[_aquisição_](pt/editor/aquisição)|Configurações de aquisição em nível de Item e Categoria.|
|[_combate_](pt/editor/combate)|Valores de correção de combate para ações do tipo resistência.|
|[_propriedade_](pt/editor/propriedade)|Configuração dos efeitos de um Item.|
