
# componente
Partes comuns
- Os componentes comuns usados em cada configuração de local são extraídos e manipulados.
- Os componentes usados em todas essas áreas são comuns, mas nada é usado em alguns dos itens.

|componente|Descrição|
|-|-|
|[_information_](pt/editor/information)|Configuração de informações básicas sobre o elemento (ID, nome, ícone, cor, etc.)|
|[_requirement_](pt/editor/requirement)|Configuração dos requisitos necessários para o uso e exibição de elementos.|
|[_acquisition_](pt/editor/acquisition)|Configurações de aquisição em nível de Item e Categoria.|
|[_combat_](pt/editor/combat)|Valores de correção de combate para ações do tipo resistência.|
|[_property_](pt/editor/property)|Configuração dos efeitos de um Item.|
