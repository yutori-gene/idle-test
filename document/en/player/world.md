
# world
You can operate and check the game's general controls and configurations,
___

## overview
About this game
- このゲームのワールド（世界観・設定）について確認できる
- このゲームを動かしているコンソール（システム）も確認できる
___

## statistics
Summary of progress
- これまでのゲームの進行状況を確認できる
___

## config
Changing game configurations
- ゲームの表示や処理に関する設定を行う
- ゲームデータの読み書きやリセットが可能
___

## debug
Operation for debugging confirmation
- これはデバッグ中にのみ表示される
- ゲームの公開・配布時には表示されない
