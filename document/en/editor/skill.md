## Explanation display
Whether to show the explanatory note as a toast on activation
- A flag for whether the explanatory note is shown as a toast when this skill activates.
- When on, it is shown each time the skill activates, with a probability of (100% − activation probability) ÷ 2. An activation probability of 40% gives 30%.
- When off, it is not shown.
- If the explanatory note is blank, nothing is shown even when this is on.
