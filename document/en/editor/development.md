
# development
Notes and error management during world development
- It is used in the development of worlds.
- It is related to the development and testing of this world and does not affect the content of the play.
- Players will not be asked to confirm any details about the development.
___

## version
Editor build version number
- The console version number at the time of world creation is automatically recorded.
- The developer cannot change this content.
___

## memo
Memo records for developers
- Developers are free to include this information as a memo.
- It is not related to the publication of the game.
___

## error
Error logging of validation results
- The results of the world validation are automatically saved here.
- For example, an error will be displayed if there is a type of character that cannot be entered, or if a value is entered that exceeds the upper limit.
- The developer cannot change this content.
- Possible to store to the server when there are no errors stored here.
___

## time-stamping
Creation, storage, and publication records
- The time when a world is created, saved, and published is automatically recorded.
- The developer cannot change this content.
___

### creation-time
Time when the world was first created
- The days when the world was first created.
___

### Save date
Last save execution time
- The date and time the world was last saved.
___

### Release date
Time of last public execution
- World was last published days.
___

## automatic saving
Enable/Disable auto save function
- Indicates whether the auto save function is enabled.
- The developer cannot change this content.
