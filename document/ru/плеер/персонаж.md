
# персонаж
Идентификация и работа с ситуацией протагониста.
- Это содержимое идентично тому, что отображается при работе с категорией.
___

## активность
Список всех действий
- Длительное нажатие переключает выполнение действия.
___

## инвентарь
Список всех предметов
- Нажмите и удерживайте кнопку для переключения между предметами снаряжения.
___

## Статус.
Список всех свойств
- Показаны только значения коррекции категории по предмету.
- В зависимости от выполняемого действия возможны и другие коррекции.
___

## Миссия
Список всех задач
- Они отображаются сгруппированными по категориям.
- Задачи, для которых не указана категория, отображаются в начале списка.
- Выполненные задачи отмечаются галочкой.
- Задачи, за которые еще не получено вознаграждение, помечаются ленточкой. Для получения вознаграждения выберите задачу и нажмите «Получить».
- Задачи, которые после выполнения перестали соответствовать условиям, отмечаются перечеркнутым значком и возвращаются в статус «невыполненных».
