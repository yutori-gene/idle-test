
# игрок
Объяснение игры дается для каждого столбца, представленного в разделе "Играй в игру".
- По умолчанию одно и то же описание отображается в виде подсказки внизу каждого столбца.
- Подсказки можно скрыть с помощью конфигурации.

|игрок|説明|
|-|-|
|[_персонаж_](ru/плеер/персонаж)|Идентификация и работа с ситуацией протагониста.|
|[_категория_](ru/плеер/категория)|Компиляция из различных элементов.|
|[_действие_](ru/плеер/действие)|Элементы действия, такие как сбор, изготовление и сражения.|
|[_пункт_](ru/плеер/пункт)|Предметы.|
|[_собственность_](ru/плеер/собственность)|Проверка значений коррекции|
|[_мир_](ru/плеер/мир)|Вы можете управлять и проверять общие элементы управления и конфигурации игры,|
|[_разное_](ru/плеер/разное)|Другая дополнительная информация.|
