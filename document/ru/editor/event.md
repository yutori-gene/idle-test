
# Событие
Сообщения и награды, активирующиеся в определённый момент
- Эта функция срабатывает в определённые моменты, например, при первом открытии мира или когда игра окончена, и открывает специальный экран.
- Для каждого момента времени предусмотрено по одному полю; их нельзя ни добавлять, ни удалять. Если какой-то момент времени не используется, поле следует оставить пустым.
- Они не отображаются в списке миссий и задач. Задачи, выполнение которых считается завершенным при выполнении определенных условий, имеют конфигурацию в разделе «Задачи».
- Вознаграждение получается автоматически сразу после активации. Никаких действий по получению, как в случае с заданиями, и никаких лент не требуется.
- 発動時にカテゴリのレベル、アクションの実行回数、アイテムの所持数を変化させることができます。
- Если поля «Название», «Описание» и «Значок» оставить пустыми, будут использоваться встроенные у игрока стандартные тексты и значки.

|синхронизация|условие активации|повторить|
|-|-|-|
|`comebacked`|Когда человек возвращается из выкл. вверх на одну секунду и в процессе происходит действие.|часто|
|`gameovered`|Когда выносливость игрока заканчивается в бою.|часто|
|`welcomed`|Когда я только начал жить в этом мире.|только один раз|
|`completed`|全カテゴリのレベルが最大値（maxCategoryLevels）に達した時|только один раз|
|`obtained`|при выполнении или подтверждении действия одного типа (например, сундук)|часто|
- [_task_](ru/editor/task)
___

## При возвращении
Срабатывает при возвращении из офлайна
- Срабатывает, когда вы возвращаетесь после одной секунды или более офлайна и при этом было действие в процессе.
- Отображается вместе со сводкой прогресса за время вашего отсутствия.
___

### [_информация_](ru/editor/information)
___

### カテゴリ
イベントでは使用しません
- ミッションやタスクの一覧に表示されないため、所属するカテゴリは指定しません。
- エディターでは入力欄が表示されません。
___

### タイミング
イベントが発動するタイミング（固定）
- Зафиксировано как `comebacked` и не редактируется.
- Срабатывает при каждом возвращении, сколько угодно раз.
___

### 初期表示状態
イベントアイコンの初期表示状態（発火はタイミングで決まり、この設定では発火しません）
- イベントの発火条件はタイミングで決まり、この項目はアイコンの見た目のみに影響します。
- secreted: 全requirementsを満たすまでアイコンが表示されません（発火自体はタイミングで起こります）。
- hidden・hinted: アイコンに斜線が付き未解放として表示されます。
- released: 斜線が消え解放済みとして表示されます。
___

### 条件
報酬を獲得する条件
- タイミングが成立するとイベントは発動し、専用の画面を開いて内容を表示します。
- 報酬は、発動時にここで設定した条件を満たしている場合にのみ獲得します。
- 条件を設定していない場合は、発動するたびに報酬を獲得します。
- requiringGroupを有効にすると、ここで指定するidの意味がカテゴリ・アクション・アイテム個別のIDからグループIDに変わります。
___

#### Тип.
Тип элемента, на который ссылается условие.

|Тип.|Значения, на которые ссылаются|
|-|-|
|カテゴリ|カテゴリのレベル|
|Действие.|Количество раз, когда действие было выполнено.|
|предмет|Количество удерживаемых предметов.|
___

#### ID элемента
ID элемента, на который ссылается условие.
___

#### значение
Необходимые для выполнения требований значения.
- Условие выполняется, если значение выше или равно указанному значению.
___

#### Вероятность потребления [0-1].
Вероятность того, что предмет будет потреблен (0-1, действительно только если тип - Предмет).
- Вероятность того, что предмет будет потреблен при выполнении условия и действия.
- При `1` расход происходит всегда, при `0.5` — с вероятностью 50 %, а при `0` расхода нет.
- Значение по умолчанию — `1` (расход всегда).
- Неверно, если тип не является предметом.
___

#### снаряжение
Требуется, чтобы предмет находился в состоянии снаряжения (только если тип - Предмет) или
- При включении этого параметра необходимо не только снаряжение, но и владение предметом.
- Неверно, если тип не является предметом.
___

### Групповая агрегация
Трактовать id условия как ID группы и оценивать по сумме её участников
- При включении id, указанный в условии (requirements), трактуется как ID группы из основных настроек.
- Условие с Type Категория оценивается по сумме Уровней всех Категорий, входящих в эту группу.
- Условие с Type Действие оценивается по сумме количества выполнений всех Действий, входящих в эту группу.
- Условие с Type Предмет оценивается по сумме количества всех Предметов, входящих в эту группу, в наличии.
- Заблокированные (кроме released) элементы не включаются в сумму.
- Вероятность расхода Предмета (chance) и условие экипировки (equipment) игнорируются, ничего не расходуется. Используются только для оценки.
- При выключении id условия трактуется как раньше — как ID отдельной Категории, Действия или Предмета.
___

### 報酬
イベント発動時の報酬設定
- タイミングが成立し、かつ条件を満たしている時に得られる報酬です。
- タスクと違って受け取る操作は要らず、発動と同時に自動で獲得します。
- 数量にマイナスを設定することができます。例えばゲームオーバー時にアイテムの数量をマイナスにすれば、それらを失います。
___

#### Тип.
Тип приобретаемого элемента.

|Тип.|Что получено.|
|-|-|
|カテゴリ|Уровень (добавлено преобразование опыта)|
|Действие.|Количество выполненных операций.|
|предмет|количество имущества|
___

#### ID элемента
ID, идентифицирующий приобретаемый элемент.
___

#### значение
Значения должны быть получены.
- Минусы уменьшают количество владений, количество раз их выполнения и их уровень. Однако оно не может быть ниже 0.
- Если у Предмета есть максимальное количество владений (макс.), то количество собственных владений не будет увеличиваться сверх этого значения.
- タイプがカテゴリの場合、設定した値がレベルに直接加算されます（1で1レベル、0.5で0.5レベル）。アクションの経験値設定で調整するのが通常の方法です。特殊な目的がない限りこの設定は不要です。
___

#### Вероятность [-1…1]
Вероятность успеха получения (отрицательные значения оцениваются только в случае неудачи)
- Установите конфигурацию вероятности получения в виде десятичного числа от -1 до 1. При определении вероятности используется абсолютное значение.
- При положительном значении проверка выполняется только при успехе действия: при `1` предмет получается всегда, а при `0.5` — с вероятностью 50 %.
- При отрицательном значении проверка выполняется только при провале действия: при `-1` предмет получается всегда, а при `-0.5` — с вероятностью 50 %.
- При значении `0` он не получается ни в случае успеха, ни в случае неудачи.
- Значение по умолчанию — `1` (обязательно получается в случае успеха).
___

### タスクグループ
イベントでは使用しません
- ミッションやタスクの一覧に表示されないため、グループの指定は使いません。
- エディターでは入力欄が表示されません。
___

## При поражении
Срабатывает, когда в бою заканчивается выносливость
- Срабатывает, когда выносливость игрока заканчивается в бою.
- Если задать отрицательное количество награды, поражению можно назначить цену.

- Минусы уменьшают количество владений, количество раз их выполнения и их уровень. Однако оно не может быть ниже 0.
- Если у Предмета есть максимальное количество владений (макс.), то количество собственных владений не будет увеличиваться сверх этого значения.
- タイプがカテゴリの場合、設定した値がレベルに直接加算されます（1で1レベル、0.5で0.5レベル）。アクションの経験値設定で調整するのが通常の方法です。特殊な目的がない限りこの設定は不要です。
___

#### Вероятность [-1…1]
Вероятность успеха получения (отрицательные значения оцениваются только в случае неудачи)
- Установите конфигурацию вероятности получения в виде десятичного числа от -1 до 1. При определении вероятности используется абсолютное значение.
- При положительном значении проверка выполняется только при успехе действия: при `1` предмет получается всегда, а при `0.5` — с вероятностью 50 %.
- При отрицательном значении проверка выполняется только при провале действия: при `-1` предмет получается всегда, а при `-0.5` — с вероятностью 50 %.
- При значении `0` он не получается ни в случае успеха, ни в случае неудачи.
- Значение по умолчанию — `1` (обязательно получается в случае успеха).

### 初期表示状態
イベントアイコンの初期表示状態（発火はタイミングで決まり、この設定では発火しません）
- イベントの発火条件はタイミングで決まり、この項目はアイコンの見た目のみに影響します。
- secreted: 全requirementsを満たすまでアイコンが表示されません（発火自体はタイミングで起こります）。
- hidden・hinted: アイコンに斜線が付き未解放として表示されます。
- released: 斜線が消え解放済みとして表示されます。

### 条件

- タイミングが成立するとイベントは発動し、専用の画面を開いて内容を表示します。
- 報酬は、発動時にここで設定した条件を満たしている場合にのみ獲得します。
- 条件を設定していない場合は、発動するたびに報酬を獲得します。
- requiringGroupを有効にすると、ここで指定するidの意味がカテゴリ・アクション・アイテム個別のIDからグループIDに変わります。

### Групповая агрегация
Трактовать id условия как ID группы и оценивать по сумме её участников
- При включении id, указанный в условии (requirements), трактуется как ID группы из основных настроек.
- Условие с Type Категория оценивается по сумме Уровней всех Категорий, входящих в эту группу.
- Условие с Type Действие оценивается по сумме количества выполнений всех Действий, входящих в эту группу.
- Условие с Type Предмет оценивается по сумме количества всех Предметов, входящих в эту группу, в наличии.
- Заблокированные (кроме released) элементы не включаются в сумму.
- Вероятность расхода Предмета (chance) и условие экипировки (equipment) игнорируются, ничего не расходуется. Используются только для оценки.
- При выключении id условия трактуется как раньше — как ID отдельной Категории, Действия или Предмета.
___
