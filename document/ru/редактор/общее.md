
# общий
Основные настройки игры, включая конфигурации языка и уровня
___

## Язык.
Язык мира на момент его создания.
- Конфигурация языка, используемого в этом редакторе мира.
- Первый язык, отображаемый при запуске игры.
___

## перевод
Подготовка переводов на несколько языков или
- Если эта функция включена, пользователи могут играть на любом языке.
- Если эта функция отключена, вы можете воспроизводить только на языке, выбранном в конфигурации языка.
- Если перевод включен, необходимо предоставить переведенные данные для каждого языка.
- [_translation_](ru/редактор/перевод)
___

## Макс. время выкл. [часы].
Ограничения по времени на прогресс в выкл.
- Конфигурация максимального количества времени прогресса в режиме выкл.
- Например, если задано 6 часов, будет обработан процесс возвращения в выкл. до 6 часов, но если на возвращение в выкл. отведено больше времени, время выкл. будет считаться равным 6 часам.
- Если установлено время 0, то при возвращении в выкл. обработка процесса вообще не происходит.
- Максимальное значение - 24 часа.
- [_category_](ru/редактор/категория)
___

## Максимальный уровень категории
Уровень вверх для категории.
- Конфигурация максимального уровня для категории.
- Если опыт получен сверх этого уровня, то при расчете каждого свойства используется максимальное значение, установленное здесь.
- Это значение не имеет отношения к категориям без уровней.
- [_category_](ru/редактор/категория)
___

## функция заблокировано
Скрывайте предметы до тех пор, пока не будут выполнены все требования
- Если эта опция включена, действие категории будет скрыто, если оно ничего не использовало или не имело, а требования не были выполнены.
- Если отключить эту функцию, все пункты будут отображаться с самого начала, но их выполнение или снаряжение невозможно до тех пор, пока не будут выполнены все требования.
- [_category_](ru/редактор/категория)
- [_action_](ru/редактор/действие)
- [_item_](ru/редактор/пункт)
___

## валюта
Конфигурация валюты (монет), используемой в игре
- Определите конфигурацию валюты, используемой в игре.
- Можно определить количество валют, для каждой из которых осуществляется конфигурация (ID, название, значок, цвет и т. д.).
- Валюта используется для покупки и продажи предметов, а также для расширения объёма инвентаря.
- Первая валюта рассматривается как основная и используется в тех случаях, когда для предметов или емкости не указан ID валюты (`coinId`).
- [_information_](ru/редактор/информация)
- [_item_](ru/редактор/пункт)
___

## емкость
Конфигурации емкости инвентаря.
- Контролирует максимальное количество различных типов предметов, которые может иметь игрок.
- Каждый предмет контролируется количеством типов предметов, которые у вас есть, а не количеством собственных предметов.
- Установка `initialCount` в 0 означает неограниченную емкость.
- Если вы ссылаетесь на предметы потенциала в условиях или наградах, используйте конфигурацию, указанную здесь.
- [_item_](ru/редактор/пункт)
___

### [_информация_](ru/редактор/информация)
___

### Значение по умолчанию [шт].
Первоначальная вместимость инвентаря (количество различных предметов, которые можно хранить)
- Начальная вместимость (количество различных предметов, которыми можно владеть) в начале игры.
- Если установлено значение `0`, емкость не ограничена.
___

### Базовая цена [монеты].
Начальная цена за одну дополнительную емкость.
- Базовая цена (в монетах) за увеличение вместимости инвентаря на один слот.
- Фактическая цена рассчитывается как "базовая цена х процентное увеличение ^ количество раз, которое купили".
- Пример: базовая цена 100, коэффициент повышения 1,2, первая 100 монет, вторая 120 монет, третья 144 монеты.
___

### Увеличение в процентах [раз].
Процентное увеличение затрат на расширение мощностей
- Это мультипликатор, показывающий, насколько увеличиваются затраты на расширение мощностей с n-й покупкой.
- Для `1.0` цена всегда одинакова, для `1.2` цена увеличивается на 20% каждый раз, когда его покупают.
- Формула: базовая цена х процентное увеличение ^ количество раз, которое можно купить

|темп роста|1-е дополнение.|5-е увеличение.|Десятое увеличение.|Сотое увеличение.|1000-е увеличение.|
|-|-|-|-|-|-|
|1.00|x1.00|x1.00|x1.00|x1.00|x1.00|
|1.05|x1.00|x1.22|x1.63|x131.50|x1.7×10²⁰|
|1.10|x1.00|x1.61|x2.59|x1.4 x 10⁴|x2.7×10⁴¹|
|1.20|x1.00|x2.49|x6.19|x8.3 x 10⁷|x8.3×10⁷⁹|
|1.50|x1.00|x5.06|x57.67|x1.9×10¹⁷|x7.0×10¹⁷⁶|
___

### Идентификатор валюты
ID валюты, используемой для увеличения объёма
- Укажите ID валюты (coins), которая будет использоваться для оплаты расширения объёма инвентаря.
- Если поле оставлено пустым, используется основная валюта (первая в списке «coins»).
___

### Максимальное количество покупок [раз]
Максимальное количество раз, когда можно купить емкость
- Это максимальное количество раз, когда можно купить объем за валюту.
- Если установить значение `0`, можно будет купить что-то без ограничений.
- Если установить значение `-1`, нельзя будет купить что-то.
- Увеличение емкости за счет вознаграждений не подпадает под действие этого ограничения.
___

## Кью
Конфигурация количества слотов для последовательного выполнения действий (запланированных)
- Управляет количеством слотов для последовательного выполнения действий (запланированных).
- Количество ячеек, как и вместимость, можно купить за валюту, а также увеличить, указав предметы из очереди в качестве награды за действия или события.
- При обращении к предметам очереди по условиям или вознаграждениям используйте ID, конфигурированный здесь.
- [_item_](ru/редактор/пункт)
___

### [_информация_](ru/редактор/информация)
___

### Значение по умолчанию [шт].
Количество ячеек для последовательного выполнения при начале игры
- Количество мест, зарезервированных на момент, когда начинается игра.
- Минное значение — `1` (значение `0`, означающее «без ограничений», как в случае с емкостью, не используется).
___

### Базовая цена [монеты].
Начальная цена за добавление одного места
- Это базовая стоимость (в монетах) за увеличение количества слотов для последовательного выполнения на один.
- Фактическая цена рассчитывается как "базовая цена х процентное увеличение ^ количество раз, которое купили".
- Пример: базовая цена 100, коэффициент повышения 1,2, первая 100 монет, вторая 120 монет, третья 144 монеты.
___

### Увеличение в процентах [раз].
Темпы роста затрат на расширение мощностей
- Коэффициент, отражающий, насколько возрастают затраты на расширение квоты при n-й покупке.
- Для `1.0` цена всегда одинакова, для `1.2` цена увеличивается на 20% каждый раз, когда его покупают.
- Формула: базовая цена х процентное увеличение ^ количество раз, которое можно купить
___

### Идентификатор валюты
ID валюты, используемой для расширения лимита
- Укажите ID валюты (coins), которая будет использоваться для расчета стоимости расширения окна непрерывного выполнения.
- Если поле оставлено пустым, используется основная валюта (первая в списке «coins»).
___

### Максимальное количество покупок [раз]
Максимальное количество раз, когда можно купить квоту
- Максимальное количество раз, которое можно купить за валюту в рамках серии выполнений.
- Если установить значение `0`, можно будет купить что-то без ограничений.
- Если установить значение `-1`, нельзя будет купить что-то.
- Увеличение квоты за счет вознаграждения не подпадает под действие этого ограничения.
___

## Значение роста опыта [раз].
Процентное увеличение сложности уровня.
- С повышением уровня категории увеличивается скорость роста опыта, необходимого для достижения следующего уровня.
- Увеличение этого значения повышает уровень сложности.
- Количество очков опыта, необходимое для перехода на следующий уровень, равно (коэффициент прироста очков опыта)^(текущий уровень - 1).

|Темпы роста опыта|Lv.1|Lv.2|Lv.10|Lv.50|Lv.99.|
|-|-|-|-|-|-|
|0|x1.00|x1.00|x1.00|x1.00|x1.00|
|0.02|x1.00|x1.02|x1.22|x2.69|x5.52|
|0.05|x1.00|x1.05|x1.55|x11.47|x131.50|
|0.10|x1.00|x1.10|x2.36|x117.39|x5.7×10⁴|
|0.20|x1.00|x1.20|x6.19|x3.3 x 10³|x1.3 x 10¹¹|
- [_category_](ru/редактор/категория)

## ограничение уровня действия
Запрашивает количество раз выполнения действия с одним и тем же атрибутом для выполнения действия.
- Если эта опция включена, то к условиям выполнения каждого действия автоматически добавляется количество раз, когда выполнялось действие с теми же атрибутами.
- Необходимое количество раз равно значению уровня действия.
- Если ничего не задано в конфигурации атрибута, используется ID категории, к которой он принадлежит.
