
# дизайн
Конфигурации внешнего вида, такие как цвета и шрифты мира.
- Конфигурации отображения миров.
- Что касается общего дизайна мира, то если для каждого элемента есть индивидуальные конфигурации, то они имеют приоритет.
___

## преобладающий цвет
Основные цвета мира
- Используется в качестве цвета барной стойки.
- Противоположный цвет используется для теней на полоске.
___

## дополнительный цвет
Вспомогательные цвета для фона и текста
- Цвет, используемый в качестве фона и цвета текста.
- Оттенки, близкие к основному цвету, будут сливаться с ним.
___

## 影色
バーの影のカラー
- バーやヘッダーに落ちる影の色として使用されます。
- バー色よりも暗い色にすると自然な影になります。
___

## фоновое изображение
Фоновое изображение для всей игры
- Конфигурация фонового изображения игры.
- Если конфигурация изображения не задана, фон будет градиентным на основе вспомогательного цвета.
