
# дизайн
Конфигурации внешнего вида, такие как цвета и шрифты мира.
- Конфигурации отображения миров.
- Что касается общего дизайна мира, то если для каждого элемента есть индивидуальные конфигурации, то они имеют приоритет.
___

## Цвет панели
Цвет фона бара
- Используется в качестве фона для панели.
- Поскольку этот цвет служит фоном для всего экрана, на его основе формируются цвета выделенной строки и полосы прокрутки.
___

## Цвет текста
Цвет текста и фона
- Используется в качестве цвета шрифта.
- Если ничего не задано для фонового изображения, в качестве фона будет использоваться градиент, основанный на этом цвете.
- Если увеличить контраст между цветом штрихов и фоном, текст станет более читабельным.
___

## Цвет тени
Цвет тени бара
- Используется в качестве цвета тени, падающей на панели и заголовки.
- Если выбрать цвет темнее, чем цвет полосы, получится естественная тень.
___

## фоновое изображение
Фоновое изображение для всей игры
- Конфигурация фонового изображения игры.
- Если изображение не указано, в качестве фона будет использоваться градиент, основанный на цвете текста.
