
# Событие
Сообщения и награды, активирующиеся в определённый момент
- Эта функция срабатывает в определённые моменты, например, при первом открытии мира или когда игра окончена, и открывает специальный экран.
- Для каждого момента времени предусмотрено по одному полю; их нельзя ни добавлять, ни удалять. Если какой-то момент времени не используется, поле следует оставить пустым.
- Они не отображаются в списке миссий и задач. Задачи, выполнение которых считается завершенным при выполнении определенных условий, имеют конфигурацию в разделе «Задачи».
- Вознаграждение получается автоматически сразу после активации. Никаких действий по получению, как в случае с заданиями, и никаких лент не требуется.
- Он может изменять уровень категории, количество выполняемых действий и количество предметов, которыми можно обладать при активации.
- Если поля «Название», «Описание» и «Значок» оставить пустыми, будут использоваться встроенные у игрока стандартные тексты и значки.

|синхронизация|условие активации|повторить|
|-|-|-|
|`Возвращение`.|Когда человек возвращается из выкл. вверх на одну секунду и в процессе происходит действие.|часто|
|`gameovered`.|Когда выносливость игрока заканчивается в бою.|часто|
|Добро пожаловать.|Когда я только начал жить в этом мире.|только один раз|
|`завершено`.|Когда достигнут макс. уровень всех категорий (maxCategoryLevels).|только один раз|
|`obtained`|при выполнении или подтверждении действия одного типа (например, сундук)|часто|
- [_task_](ru/редактор/задача)
___

## При возвращении
Активируется при возвращении из режима выключения
- Эта функция срабатывает, если после перехода в автономный режим прошло более 1 секунды, а затем система вернулась в рабочий режим и в этот момент действие было в процессе.
- Отображается вместе с сводкой прогресса за время отсутствия.
___

### [_информация_](ru/редактор/информация)
___

### Категория.
Не используется в рамках события
- Поскольку это не отображается в списке миссий и задач, категорию не указываем.
- В редакторе поле ввода не отображается.
___

### синхронизация
Момент срабатывания события (фиксированный)
- Значение зафиксировано как `comebacked` и не подлежит редактированию.
- Активируется каждый раз при возвращении, сколько угодно раз.
___

### Начальное состояние отображения
Начальное состояние отображения значка события (срабатывание зависит от момента времени; при данной конфигурации событие не срабатывает)
- Условия срабатывания события определяются временем, а этот параметр влияет только на внешний вид значка.
- secreted: Иконка не отображается до тех пор, пока не будут выполнены все требования (само срабатывание происходит в заданный момент).
- hidden・hinted: на значке появляется перечеркивающая линия, и он отображается как «неразблокированный».
- released: Косая черта исчезнет, и элемент будет отображаться как «освобожденный».
___

### правила и условия
Условия получения вознаграждения
- Когда условия срабатывают, событие активируется, и открывается специальный экран, на котором отображается соответствующая информация.
- Вознаграждение выплачивается только в том случае, если при срабатывании условия, установленной здесь, выполняются условия конфигурации.
- Если условий нет, вы будете получать вознаграждение при каждом срабатывании.
___

#### Тип.
Тип элемента, на который ссылается условие.

|Тип.|Значения, на которые ссылаются|
|-|-|
|Категория.|Категория на уровне.|
|Действие.|Количество раз, когда действие было выполнено.|
|предмет|Количество удерживаемых предметов.|
___

#### ID элемента
ID элемента, на который ссылается условие.
___

#### значение
Необходимые для выполнения требований значения.
- Условие выполняется, если значение выше или равно указанному значению.
___

#### Вероятность потребления [0-1].
Вероятность того, что предмет будет потреблен (0-1, действительно только если тип - Предмет).
- Вероятность того, что предмет будет потреблен при выполнении условия и действия.
- Всегда расходуется при `1`, с вероятностью 50% расходуется при `0,5` и не расходуется при `0`.
- Значение по умолчанию - `1` (всегда потребляется).
- Неверно, если тип не является предметом.
___

#### снаряжение
Требуется, чтобы предмет находился в состоянии снаряжения (только если тип - Предмет) или
- При включении этого параметра необходимо не только снаряжение, но и владение предметом.
- Неверно, если тип не является предметом.
___

### вознаграждение
Конфигурации вознаграждения при наступлении события.
- Это вознаграждение, которое получается при соблюдении определённого момента времени и выполнении определённых условий.
- В отличие от заданий, для получения не требуется выполнять никаких действий — получение награды происходит автоматически сразу после активации.
- Можно установить отрицательное значение количества. Например, если при том, что игра окончена, количество предметов будет отрицательным, вы их потеряете.
___

#### Тип.
Тип приобретаемого элемента.

|Тип.|Что получено.|
|-|-|
|Категория.|Уровень (добавлено преобразование опыта)|
|Действие.|Количество выполненных операций.|
|предмет|количество имущества|
___

#### ID элемента
ID, идентифицирующий приобретаемый элемент.
___

#### значение
Значения должны быть получены.
- Минусы уменьшают количество владений, количество раз их выполнения и их уровень. Однако оно не может быть ниже 0.
- Если у Предмета есть максимальное количество владений (макс.), то количество собственных владений не будет увеличиваться сверх этого значения.
- Если тип - категория, значение конфигурации добавляется непосредственно к уровню (1 - 1 уровень, 0,5 - 0,5 уровня). Обычный способ настроить это - конфигурация опыта действия. Эта конфигурация не нужна, если нет ничего особенного.
___

#### Вероятность [-1…1]
Вероятность успеха получения (отрицательные значения оцениваются только в случае неудачи)
- Установите конфигурацию вероятности получения в виде десятичного числа от -1 до 1. При определении вероятности используется абсолютное значение.
- Если значение положительное, оценка производится только в случае успеха при выполнении действия: при значении `1` предмет получается обязательно, а при значении `0.5` — с вероятностью 50 %.
- Если значение отрицательное, оценка производится только в случае неудачи действия: при значении `-1` предмет обязательно получается, а при значении `-0.5` — с вероятностью 50 %.
- При значении `0` он не получается ни в случае успеха, ни в случае неудачи.
- Значение по умолчанию — `1` (обязательно получается в случае успеха).
___

### целевая группа
Не используется в рамках события
- Поскольку это не отображается в списке миссий и задач, мы не используем указание группы.
- В редакторе поле ввода не отображается.
___

Активируется, когда в бою заканчивается выносливость
- Активируется, когда у игрока заканчивается выносливость в бою.
- Если установить значение Минус для количества вознаграждения, можно ввести штраф за то, что игра окончена.
