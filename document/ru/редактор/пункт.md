
# предмет
Элементы товаров, такие как снаряжение и расходные материалы
- Этот элемент относится к собственным объектам, таким как снаряжение, расходные материалы и ценности.
- В категории может быть только одно снаряжение, либо оно может быть ничего не включать.
- Существует также различное количество способов их использования.

## Категория.
ID категории, к которой относится данный предмет
- Укажите ID категории, к которой относится данный предмет.
___

## группа (обычно люди)
Отображение групповой классификации минут
- Примените одну из конфигураций групп в разделе Basic.
- Список предметов отображается в порядке конфигурации групп.
- Если оставить пустым, то группировка не производится.
- [_general_](ru/редактор/общее)
___

## Исходное состояние разблокировки
Начальное состояние отображения и освобождения элемента (при выполнении условий активации автоматически переходит в более высокое состояние)
- secreted: Не отображается в пользовательском интерфейсе до тех пор, пока не будут выполнены все требования (не появляется в Подсказках и скрывается в списке требований/наград).
- hidden: Пока на него не ссылается ни один из элементов разблокировки и не выполнены все условия, он полностью скрыт (его название отображается серым цветом и недоступно для взаимодействия).
- hinted (по умолчанию): отображается только название, но с ним нельзя работать, пока оно не будет разблокировано.
- released: Освобождается и становится доступным для управления с самого начала, независимо от условий (ранее — «Отображать с самого начала»).
___

## Значение [монеты].
Конфигурация цены покупки предметов.
- Предмет нельзя купить, если вы никогда им не обладали.

|значение|лечение|
|-|-|
|0|ничего|
|Значение больше нуля.|Значение, по которому вы можете купить.|
|Значение меньше нуля (например, -1)|Ничего нельзя купить (считается нулем).|
___

## Значение [монеты].
Конфигурация цены продажи предметов.
- Конфигурация цены, по которой будут проданы предметы.

|значение|лечение|
|-|-|
|0|ничего|
|Значение больше нуля.|Продавайте по этому значению.|
|Значение меньше нуля (например, -1)|Общая конфигурация ставки скидки, умноженной на цену предложения (если значение цены предложения равно нулю, то ничего продать нельзя)|
- [_general_](ru/редактор/общее)
___

## Собственное макс. количество [шт].
Ограничение на максимальное количество собственных предметов.
- Если 0, то собственное количество не ограничено.
- Если вверху больше 1, вы можете владеть только собственным количеством. Если максимальный лимит достигнут, дальнейшие приобретения не увеличат собственное количество.
___

## тип оборудования
Тип конфигурации для снаряжения, эффектов и потребления предметов.
- Предметы, на которые можно нанести снаряжение, необходимо отнести к группе, указанной в категории `equipmentGroups`.
- В одной группе можно снарядить только один предмет.

|значение|снаряжение|Эффективность.|потребление|Пример.|
|-|-|-|-|-|
|Необходимый.|Необходимо|Снаряжение|ничего|Мечи, доспехи и другое снаряжение.|
|`расходуемый`.|Необходимо|Снаряжение|Потребляется при выполнении действий|Предметы, которые потребляются для получения эффекта, например, зелья.|
|`Необходимо`.|Не нужно|В любое время, пока вы находитесь в руках.|ничего|Предметы, которые эффективны только благодаря их наличию.|
|Невозможно.|не разрешается|ничего|ничего|Предметы, которые ничего не дают, например, материалы и мусор.|

## ID торгуемой валюты
ID валюты, используемой для покупки и продажи этого предмета
- Укажите ID валюты (coins), которая используется как для покупки, так и для продажи.
- Если поле оставлено пустым, используется основная валюта (первая в списке «coins»).
