
# боевое значение
Боевые значения коррекции для действий типа "Выносливость".
- Значения коррекции действительны только для действий типа `stamina`.
- Каждое значение рассчитывается как дополнительная коррекция разницы в уровне между игроком и действием.
- Например, если значение атаки равно 10, урон от атаки рассчитывается так, как если бы уровень игрока был на 10 выше уровня действия. Если значение равно Минусу, коррекция происходит в обратном направлении.
- При конфигурации `defaultCombat` в `Общем` он становится боевым параметром по умолчанию для всего мира.
___

## Значение атаки [разница уровней].
Коррекция уровня урона выносливости, наносимого противникам.
- Чем выше значение, тем больше урона наносится.
___

## Значение защиты [разница уровней].
Коррекция уровня урона выносливости, получаемого от противников.
- Чем выше значение, тем больше снижается урон.
___

## Значение точности [разница уровней].
Коррекция разницы уровней на количество промахов при атаке.
- Чем выше значение, тем ниже процент ошибок.
___

## Значение уклонения [разница уровней].
Коррекция уровня уклонения от атак противника.
- Чем выше значение, тем легче избежать уклонения от атаки противника.
___

## Восстановить значение [разница уровней].
Коррекция разницы уровней для восстановления выносливости.
- Чем выше значение, тем больше выносливости можно восстановить.
