
# перевод
Конфигурации для перевода игрового текста на другие языки.
- Конфигурация текста для перевода.
- Конфигурации на нескольких языках доступны, если включены настройки перевода.
- Если перевод отключен, то информация, описанная во время разработки, будет отображаться как есть.
- Конфигурации перевода и переключение языков невозможны во время предпубликационной подготовки.
___

## Активация перевода
Выкл. конфигурации функции перевода.
- Конфигурации на нескольких языках доступны, если включены настройки перевода.
- Перевод не активируется во время разработки до публикации. Переключение между языками будет включено после публикации.
- Если перевод включен, поддерживается десять различных языков, и для всех языков необходимо иметь данные перевода. Невозможно включить только некоторые языки.
- Когда пользователь запускает игру, сначала отображается язык, используемый при разработке. Затем язык можно изменить на любой другой.
- Процесс перевода утомителен, но он позволяет многим людям играть с ним.
___

## языковой файл
JSON-файл с данными перевода.
- При выводе игровых данных с общедоступными конфигурациями в папке `translations/world` создается JSON-файл для перевода.
- Файлы JSON для перевода на каждый язык находятся в папке. Содержимое содержит ничего не переведенного.
- У содержимого каждого типа есть свой идентификатор. Кроме того, внутри него есть название и описание.
- Необходимо сделать и сохранить переводы для всех названий и описаний.
___

## Переводческие задачи
Редактирование данных перевода
- Все файлы перевода содержат данные на том языке, на котором они были разработаны.
- Необходим перевод файлов не на тот язык, на котором они были разработаны.
___

### AI
Перевод на основе искусственного интеллекта
- Переводите с помощью искусственного интеллекта, например ChatGPT, Copilot и Claude.
- Возможно перевести сразу и качественно.
- Это может быть ничего не значащий перевод, особенно для технических терминов и собственных существительных.
- В зависимости от объема переводов использование искусственного интеллекта может быть дорогостоящим.
- Если прогресс перевода ИИ прерван на середине процесса, можно сказать ИИ "продолжить", и он справится. (В некоторых случаях это может ничего не дать).
___

#### Пример подсказок
Примеры инструкций по переводу, передаваемых ИИ
- Пример запроса: переведите значения `name` и `explanation` загруженных JSON-данных с английского на японский. Ничего не меняйте в других минутах данных.
___

#### Использование GPT
Перевод с помощью GPT от ChatGPT.
- Переводчик языка JSON, входящий в состав библиотеки GPT, предоставляемой ChatGPT, может быть использован для перевода JSON с легкостью.
- Структура JSON сохраняется при переводе.
- Аналогичные функции могут предлагать и другие сервисы искусственного интеллекта, кроме ChatGPT.
___

### услуга перевода
Использование услуг переводчика
- Переведите с помощью таких вкл. сервисов, как DeepL и Google Translate.
- Можно рассчитывать на более высокое качество перевода по сравнению с переводом AI, но за это взимается плата в зависимости от объема перевода
- Файлы JSON ничего не могут быть переведены напрямую службами перевода, поэтому необходимо создать и использовать программу.
- За определенную плату существуют сервисы, которые переводят данные JSON как есть. (например, doctranslator.com)
___

### руководство (эксплуатация)
Ручной перевод
- Откройте файл перевода в текстовом редакторе и введите переведенное содержимое на каждом языке. Это отнимает много времени, но возможно перевести файл именно так, как вы хотите.
___
