
# Übersicht.
Grundlegende Informationen über die Welt und ihre Autoren
- In diesem Abschnitt wird der Inhalt der Welt beschrieben.
- Konfigurieren Sie es so, dass es für die Benutzer leicht zu verstehen ist, wenn sie eine Welt auswählen.
- Diese Konfigurationen haben keinen Einfluss auf den Betrieb der Welt.
___

## [_Informationen_](de/Herausgeber/Informationen)
___

## Version
Nummer der Version der Welt
- Geben Sie einen beliebigen Wert (ganze Zahl oder Dezimalzahl) ein.
- Allgemein steht der ganzzahlige Teil für die Hauptversion und der Minutenteil für die Nebenversion.
___

## Name des Autors
Name des Welt-Autors
- Geben Sie Ihren Benutzernamen oder Spitznamen ein.
___

## Startseite.
URL der Website des Autors
- Wenn Sie eine eigene Startseite oder ein soziales Netzwerk haben, geben Sie deren URL ein.
- Spieler können diese URL über einen Link überprüfen.
- Falls nicht zutreffend, leer lassen.
___

## Uniform Resource Locator
URL des Spiels
- Geben Sie die URL ein, unter der Sie das Spiel in dieser Welt platzieren möchten.
- Geben Sie die URL der ersten Seite ein, z. B. index.html, einschließlich der Domain.
- Wenn eine geeignete URL angegeben wird, wird sie als PWA betrieben.
- Eine PWA ist eine Funktion, die wie eine App funktioniert, die installiert und aus gespielt werden kann.
___

## Geschätzte Spielzeit
Geschätzte Zeit bis zum Abschluss der Welt-Spiel.
- Die geschätzte Zeit, die notwendig ist, um das Spiel in der Welt abzuschließen.
- Die Spieler können sich beim Spielen daran orientieren.
- Es handelt sich lediglich um eine Referenzzeit, und es gibt keine klare Definition dafür, was die Vollendung einer Welt ausmacht.
___

### Wert
Werte der Spielzeit
___

### Einheit
Zeiteinheit (z. B. Stunden, Minuten)
