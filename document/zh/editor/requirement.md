
# 条款和条件
配置使用和展示元素的必要条件。
- カテゴリ、アクション、アイテムごとの各要素に設定する条件です。
- 若无满足所有配置条件，则无法执行表中所示操作。
- 如果启用了锁定功能，元素本身就会被隐藏，直到满足条件为止。

|配置地点|只有满足条件才能做的事。|
|-|-|
|カテゴリ|カテゴリ内の全てのアクションの実行とアイテムの操作|
|动作。|执行动作|
|物品|操纵物品（如装备）|
- [_type_](zh/editor/type)
___

## 类型。
作为条件引用的元素类型。

|类型。|参考值|
|-|-|
|カテゴリ|カテゴリのレベル|
|动作。|执行该动作的计数。|
|物品|持有物品的计数。|
___

## 元素的 ID
作为条件的元素的 ID。
___

## 值
条件要求的数值。
- 如果值大于或等于指定值，则满足条件。
___

## 消费概率 [0-1]。
物品被消费的概率（0-1，仅在类型为物品时有效）。
- 满足条件并执行动作时，物品被消耗的概率。
- `1` 时必定消耗，`0.5` 时以 50% 的概率消耗，`0` 时不消耗。
- 默认值为 `1`（必定消耗）。
- 如果类型不是物品，则无效。
___

## 装备
要求物品处于装备状态（仅在类型为物品时有效）或
- 启用后，物品必须装备无。
- 如果类型不是物品，则无效。
