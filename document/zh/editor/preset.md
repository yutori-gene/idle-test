
# 预置
自定义显示系统元素
- 替换预先集成到游戏引擎（玩家）中的用户界面文本和图标。
- 只有通过 ID 与现有预设匹配的预设才会被替换。
- 只有您配置的项目才会被替换。例如，如果只配置了图标，名称和颜色等其他项目将使用原来的。
- 名称和说明的覆盖内容将优先于玩家内置的各语言翻译。被覆盖的字符串将以原样显示在所有语言中。
- 如果希望根据不同语言更改文本内容，请启用翻译功能，并在生成的`translations/world`翻译文件中进行指定。该文件具有最高优先级。
___

## ID
标识元素的唯一 ID
- ID 来唯一标识每个元素。
- 在编辑器中，这是一个用于标识元素的字符串。
- 例如，ID 指定了动作完成后获得的物品。

!> 一旦配置了 ID，游戏发布后就无须更改。更改它将导致与现有游戏数据不一致，游戏将无法正常运行。
___

### 显示名称。
根据 ID 自动生成的显示名称
- 可使用的字符是字母、连字符和计数的组合。
- 如果尚未配置名称，则每个单词的第一个字母大写，连字符用空格代替，并自动配置在名称中。
- 对于英语以外的语言，必须单独配置名称条目。
___

#### 例如
ID 转换的真实案例
- 如果 ID 为 `stylish-strong-axe`，名称将变为 `Stylish Strong Axe`。
___

### 无重复。
禁止在同一类型中重复 ID。
- 无须在类别、动作、物品、事件和预设类型中重复，因为它们用于标识元素。
- 不同类型使用相同的 ID 并不是问题。
- [_type_](zh/editor/type)
___

## 名称：
出现的元素名称
- 游戏中显示的元素名称。
- 也可输入英语以外的语言。
- 可以接受与其他元素重复的名称。
- 过长时，游戏过程中显示溢出的部分将以 `…` 省略。
___

### 从 ID 自动转换
根据 ID 自动生成名称
- 如果该字段留空，则会根据 ID 自动显示信息。有关详细信息，请参阅上一节。
___

## 注释
详细元素说明。
- 游戏中显示的元素说明。
- 可输入英语以外的语言。可显示所有文本，即使是长文本。
- 如无解释，则留空。
___

## 图标
配置代表元素的图标。
- 图标可配置为图像、Iconify 或表情符号。
- Iconify 是一项提供各种图标的服务。
- 如果配置了一个以上，则依次优先使用图像、Iconify 和象形图。
___

### 图片
使用任何图像文件
- 代表元素的图像。
- 如果文件大小较大，则会自动调整大小。
- 如果配置了 Iconify 或象形图，则不必要。
___

#### 文件类型
支持的图像文件格式
- 可以使用浏览器能够显示的常见格式。
- 例如 JPEG、PNG、GIF、WebP、SVG 等。
___

### 图示化
使用 Iconify 图标集
- 代表元素的图标。
- Iconify 是一项提供各种图标的服务。
- 如果已配置图像，则优先使用该图像。
___

#### 图示化
如何从 Iconify 选择图标
- 可显示的图标请从 `Iconify` 中搜索。
- 通过搜索图标，您可以快速找到最佳图标。
- 选择一个图标，查看其标识符（图标集类型`:`图标名称），如`game-icons:sword-wound`，然后直接粘贴到此图标字段中。
![iconify-selection.png](../../resources/iconify-selection.png)
- [_iconify_](https://icon-sets.iconify.design)
___

### 象形文字
带象形图的图标显示
- 将象形图显示为图标。
- 它可以从文本转换为象形图，并快速进行配置。
- 对于象形图，请按原样输入 Unicode 象形图。
- 由于使用的是在执行环境中引入的象形图，因此对于不同的用户，它们的显示方式略有不同。
- 通过 Iconify，您可以配置与每个环境无关联的表情符号
- 可以显示非图形字符，但如果有多个字符，显示可能会损坏。
- 输入象形图，例如 `🗡️` 或 `⚔️`。
___

## 颜色
配置元素的显示颜色。
- 作为元素颜色，它适用于元素的图标和背景颜色。
- 从编辑器的颜色选择器中选择。
___

### 从父元素继承
沿用父元素设置的颜色
- 留空时，将沿用父元素所设置的颜色。
- 各元素类型的层级关系如下。
- 例如，若动作设置了单独的颜色则使用该颜色；若动作未设置单独的颜色，则使用类别或世界的颜色。
- 事件在设置了类别的情况下，也会像动作和物品一样沿用该类别的颜色。
```
world
├── category
├── action
├── item
├── skill
├── group
├── task
└── preset
```
