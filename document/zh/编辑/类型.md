
# 类型。
世界的基本分类
- 世界由六种类型组成。
- 所有元素都放在世界的正下方。
- 动作和物品与所属类别的 ID 关联。

|类型。|説明|
|-|-|
|[_类别_](zh/编辑/类别)|对动作和物品进行分类的一般框架。|
|[_行动_](zh/编辑/行动)|收集、制作和战斗等行动元素。|
|[_项目_](zh/编辑/项目)|装备和消耗品等货物元素|
|[_组_](zh/编辑/组)|为类别、动作和物品定义显示组|
|[_事件_](zh/编辑/事件)|由条件触发的信息和奖励系统。|
|[_预置_](zh/编辑/预置)|自定义显示系统元素|
```
world
├── category
├── action
├── item
├── group
├── event
└── preset
```
