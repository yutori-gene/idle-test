
# personaje
Identificación y funcionamiento de la situación del protagonista.
___

## actividad
Lista de todas las Acciones
- Una pulsación larga alterna la ejecución de la acción.
___

## inventario
Lista de todos los Artículos
- Mantén pulsado para alternar el equipamiento del artículo.
___

## Estado.
Lista de todas las propiedades
- Solo se muestra el valor de la propiedad que los artículos aplican a la categoría.
- Existen además otras correcciones según la acción que se vaya a ejecutar.
___

## Misión
Lista de todas las tareas
- Las tareas se agrupan y se muestran por categoría.
- Las tareas sin categoría configurada se agrupan al principio.
- Las tareas completadas muestran una marca de verificación.
- Una cinta marca las tareas cuya recompensa aún no se ha reclamado. Selecciona una y pulsa recibir para obtenerla.
- Una vez completada, una tarea permanece completada aunque después dejen de cumplirse las condiciones.
