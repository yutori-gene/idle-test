
# Categoría.
Una recopilación de varios elementos.
- Este elemento es una recopilación de acciones y artículos.
___

## Tarea
Lista de tareas de la categoría
- Esta es la lista de tareas asignadas a esta categoría.
- Selecciona una tarea para consultar sus condiciones de finalización y su recompensa.
- Una cinta marca las tareas cuya recompensa aún no se ha reclamado. Selecciona una y pulsa recibir para obtenerla.
- No puedes reclamar una recompensa mientras el número de tipos de artículos que puedes tener esté al límite. Libera espacio y vuelve a reclamarla.
- Esto no se muestra cuando la categoría no tiene ninguna tarea.
