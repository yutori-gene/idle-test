
# Resumen.
Información básica sobre el mundo y sus autores
- Esta sección describe el contenido del mundo.
- Configúralo de forma que sea fácil de entender para los usuarios a la hora de elegir un mundo.
- Esta configuración no afecta al funcionamiento del mundo.
___

## [_información_](es/editor/información)
___

## versión
Número de versión del mundo
- Introduzca cualquier valor (entero o decimal).
- En general, la parte entera representa la versión mayor y la parte minor la versión menor.
___

## Nombre del autor
Nombre del autor mundial
- Introduce tu alias o apodo.
___

## Página de inicio.
URL del sitio web del autor
- Si tienes tu propia página de inicio o una red social, introduce su URL.
- Los jugadores pueden consultar esta URL mediante un enlace.
- Si no procede, déjelo en blanco.
___

## localizador de recursos uniformes
URL del juego
- Introduce la URL donde quieres situar el juego en este mundo.
- Introduzca la URL de la página Arriba, como index.html, incluyendo el dominio.
- Si se proporciona una URL adecuada, funcionará como una PWA.
- Una PWA es una función que funciona como una aplicación que puede instalarse y reproducirse desactivada.
___

## Tiempo estimado de juego
Tiempo estimado para completar el mundo del juego.
- Tiempo estimado Necesario para completar el juego por el mundo.
- Los jugadores pueden consultar esto como guía a la hora de jugar.
- Es sólo un tiempo de referencia y no existe una definición clara de lo que constituye la finalización de un mundo.
___

### valor
Valores del tiempo de juego
___

### unidad
Unidad de tiempo (por ejemplo, horas, minutos)
