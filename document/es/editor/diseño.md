
# diseño
Configuración del aspecto visual, como los colores del mundo y los tipos de letra.
- Configuración de la visualización de mundos.
- En cuanto al diseño global del mundo, si hay configuraciones individuales para cada elemento, tienen preferencia.
___

## color predominante
Principales colores del mundo
- Se utiliza como color de barra.
- El color opuesto se utiliza para las sombras de las barras.
___

## color suplementario
Colores auxiliares para el fondo y el texto
- Color utilizado como fondo y color del texto.
- Los tonos próximos al color principal se difuminarán.
___

## 影色
バーの影のカラー
- バーやヘッダーに落ちる影の色として使用されます。
- バー色よりも暗い色にすると自然な影になります。
___

## imagen de fondo
Imagen de fondo para todo el juego
- Configura la imagen de fondo del juego.
- Si no se configura ninguna imagen, el fondo es un degradado basado en el color auxiliar.
