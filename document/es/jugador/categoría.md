
# Categoría.
Una recopilación de varios elementos.
- Es un elemento que reúne Acciones y Artículos.
___

## Tarea
Lista de tareas de la categoría
- Esta es la lista de tareas asignadas a la categoría.
- Al seleccionar una tarea, podrás consultar los requisitos para completarla y la recompensa.
- Las tareas cuya recompensa aún no se haya recibido aparecerán marcadas con una cinta. Para recibirla, selecciona la tarea y pulsa «Obtener».
- Si una categoría no contiene ninguna tarea, no se mostrará.
