
# configuration de base
Éléments de configuration de base pour le monde en général.
- ワールドの名前、説明、背景、通貨、容量、カテゴリの最大レベル、経験値の上昇率、割引率、標準戦闘パラメータなどを設定します。
- Ces configurations affectent le monde entier.

|nom|Description|
|-|-|
|[_overview_](fr/editor/overview)|Informations de base sur le monde et ses auteurs|
|[_general_](fr/editor/general)|Paramètres de base du jeu, y compris les paramètres de langue et de niveau|
|[_design_](fr/editor/design)|Les configurations de l'apparence visuelle, telles que les couleurs du monde et les polices de caractères.|
|[_event_](fr/editor/event)|Messages et récompenses déclenchés à des moments précis|
|[_development_](fr/editor/development)|Gestion des notes et des erreurs pendant le développement du monde|
