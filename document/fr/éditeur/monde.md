
# monde
Configuration générale du monde du jeu et structure des données
- Données sur les jeux pouvant être joués sur des consoles.
- Les configurations vous permettent de créer un jeu d'abandon comme vous le souhaitez.
- Les mondes englobent les catégories, les actions, les objets et les événements.
