
# pengembangan
Catatan dan manajemen kesalahan selama pengembangan dunia
- Digunakan selama perkembangan dunia.
- Ini menyangkut pengembangan dan pengujian dunia ini dan tidak memengaruhi konten permainan.
- Pemain tidak memeriksa konten mengenai pengembangan.
___

## versi
Nomor versi build editor.
- Nomor versi konsol secara otomatis direkam pada saat pembuatan dunia.
- Pengembang tidak dapat mengubah konten ini.
___

## Memo.
Catatan memo untuk pengembang
- Pengembang bebas untuk menyertakan informasi ini sebagai catatan.
- Tidak relevan dengan publikasi game.
___

## kesalahan
Pencatatan kesalahan hasil validasi.
- Hasil validasi dunia secara otomatis disimpan di sini.
- Misalnya, kesalahan ditampilkan jika ada jenis karakter yang tidak ada, atau jika nilai yang dimasukkan melebihi batas.
- Pengembang tidak dapat mengubah konten ini.
- Ini mungkin disimpan di server bila tidak ada kesalahan yang disimpan di sini.
___

## stempel waktu
Catatan penciptaan, pelestarian, dan publikasi.
- Waktu pembuatan, penyimpanan, dan publikasi dunia direkam secara otomatis.
- Pengembang tidak dapat mengubah konten ini.
___

### hari
Waktu penciptaan dunia pertama kali
- Hari pertama kali diciptakan.
___

### simpan hari dan waktu
Waktu eksekusi penyimpanan terakhir
- Hari terakhir kali dunia diselamatkan.
___

### hari publikasi dan waktu
Waktu eksekusi publik terakhir
- Dunia terakhir kali diterbitkan pada hari.
___

## penghematan otomatis
Mengaktifkan/menonaktifkan fungsi penyimpanan otomatis.
- Menunjukkan apakah fungsi penyimpanan otomatis diaktifkan.
- Pengembang tidak dapat mengubah konten ini.
